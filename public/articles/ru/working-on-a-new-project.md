# Проект

Проект, над которым я работаю, называется LLJT:

![](assets/20260313_092734_image.png)

Это сайт, который также является PWA, то есть и мобильным приложением. Он использует MaterialUI, чтобы ощущаться как настоящее телефонное приложение.
Недавно мне пришлось заняться импортами Mui, и я сократил количество модулей с 11 707 до всего 595, импортируя каждую иконку отдельно по строке, а не через деструктуризацию: я понял, что при деструктуризации ты на самом деле загружаешь всю библиотеку иконок, а импортируя их по отдельности, ты импортируешь только те, что тебе нужны.

Nibi -- это бот, который подключён к этому сайту.![](assets/20260313_093102_image.png)Градация основана на Google Forms:
![](assets/20260313_093255_image.png)
Мы используем тесты с множественным выбором для оценки наших студентов, а также выдаём роли Discord, и соответственно эмодзи и каналы, нашим студентам, если они сдают крупный экзамен.

![](assets/20260313_093707_image.png)

Цель этого проекта -- помочь людям учить японский вместе с нами, так как я и сам хочу этим заниматься.
Студенты также будут получать партнёрские бонусы от Crunchyroll и других платформ в награду за свои способности.

Nibi и сайт хостятся соответственно на Cloudflare Workers через Hono Server Interaction URL и на GitHub Pages с React-деплоем.
Код сайта не в открытом доступе, но Nibi -- открыт, и ты можешь найти его в [этом репозитории GitHub](https://github.com/let-s-Learn-Japanese-Together/nibi). Сайт не в открытом доступе, потому что содержит личную информацию, но если хочешь узнать, как я его построил, можешь спросить меня в Discord или где-то ещё, и я с радостью расскажу! Там используется GitHub Action, который я сделал, чтобы не платить за GitHub Enterprise, а также много других крутых инструментов и техник, которыми я могу поделиться, если тебе интересно!

В последнее время мне очень нравится находить обходные пути для своих проектов, чтобы не платить за хостинг. Поэтому я сделал Nibi ботом с Interaction Endpoint -- его можно бесплатно хостить на Cloudflare Workers, и я сделал GitHub Action для бесплатного деплоя сайта на GitHub Pages. Я считаю, что поиск обходных путей -- одна из самых весёлых частей программирования, и мне это очень нравится! Нужно мыслить нестандартно и находить креативные решения проблем. Дело не просто в написании кода, а в поиске способов заставить всё работать без денег, и это вызов, который мне очень нравится.

Использование GitHub Actions не совсем по назначению и применение Cloudflare Workers для «хостинга» бота -- это также способ узнавать новое и открывать для себя новые технологии, такие как облачный хостинг, что мне тоже очень нравится. Я больше не хочу платить за хостинг.

Я всё ещё работаю над ним, но ты можешь присоединиться к [Discord-серверу](https://discord.gg/frKZ9cJ4fD), если хочешь следить за прогрессом и видеть, как он развивается, и, возможно, даже присоединиться к проекту, если тебе интересно! Сервер открыт для всех, и мы будем рады, если к нам присоединятся новые люди в этом путешествии по изучению японского! Ссылку-приглашение можно найти на сайте или спросить у меня, если хочешь!
