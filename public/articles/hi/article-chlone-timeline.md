# Chlone : Discord पर मेरी बोलचाल clone करने के छह दिन

*दिन दर दिन build वृत्तांत - itsrealfortune द्वारा*

---

यह छह दिन चले प्रोजेक्ट की सच्ची कहानी है : **Chlone**, Discord बॉट जो मेरी तरह बोलता है। मैं journey वैसे सुनाता हूँ जैसे घटी, repo के 146 commit क्रम में, घंटों, विफलताओं, चक्करों और खिड़की से सब फेंकने की इच्छाओं के साथ, लेकिन commit संदेश थोपे बिना।

सब **Fox से प्रतियोगिता** से शुरू हुआ। विषय, मजाक : हर एक को Discord पर अपना clone जीवित करना था। और मैंने **Protocol Luna** से मौलिक अलग दृष्टिकोण लिया : मैं agentique पर दाँव लगाना चाहता था, एजेंट जो यादों और उन सभी उपकरणों का उपयोग करता है जिनकी AI को जरूरत हो सकती है। भाग्य विडंबना : पूरी उपकरण पेटी चढ़ाने के बाद, मुझे सिर्फ OpenSelf MCP चाहिए था।

सिद्धांत, एक वाक्य : `chloeai` नामक [opencode](https://opencode.ai) एजेंट HTTP serveur (port 4096) पीछे चलता है, प्रति salon स्थायी सत्र रखता है, मेरी यादें OpenSelf से चुनता है, और मेरी शैली में लिखता है, मेरे असली संदेशों से `STYLE.md` में पकड़ी गई। और robot न लगने के लिए : संदेश बौछार, स्वीकृत टाइपो, ध्वनि संदेश, GIF, प्रतिक्रियाएँ, जब मैं सोता हूँ मौन, और बहुत से अन्य विवरण और तंत्र जिन्होंने दस से ज्यादा लोगों को बॉट प्रकृति पर संदेह कराया।

**OpenSelf क्या है ?**

OpenSelf स्मृति है। CLI (`openself`, `npm i -g openself` से स्थापित) जो मेरे AI एजेंटों के लिए निजी और स्थायी संदर्भ vault बनती है। repo में वह वृक्ष में प्रकट नहीं होती, लेकिन वह हर जगह है : `ecosystem.config.cjs` अभिलेख में (पहले commit से PM2 नीचे चलाए गए MCP और OpenSelf dashboard), `setup.sh` (`npm i -g openself`) में, और पूरे `tools/brain/memory.py` में।

ठोस रूप में, OpenSelf है :

- **typed यादें** (`fact`, `preference`, `decision`, `relationship`, `event`, `note`), संवेदनशीलता (public / personal / private / restricted), विश्वास नोट, स्रोत, टैग के साथ ;
- **scope** : हर याद संदर्भ की है, मेरी, या किसी सटीक व्यक्ति के लिए `discord/dm/<id>` ;
- **hybrid खोज** (शाब्दिक + सदिश) MCP में उजागर (`openself_openself_search_memory`, `openself_openself_get_context`) जिसे `chloeai` एजेंट हर उत्तर से पहले पूछता है ;
- **संघर्ष पहचान** (दिन 5 का मेरा मासिक sweep) और लेखन पर dedupe ;
- **एन्क्रिप्टेड vault** (Bitwarden में कुंजी) और सब निरीक्षण करने के लिए **स्थानीय dashboard** (port 3210) ;
- और मुझसे आलसियों के लिए : WhatsApp/Telegram इतिहास से व्यक्तित्व पोसने के लिए `openself feed`, `openself test`, `openself share` ("Talk to My Clone", web पेज), `openself arena` (दो clone बहस करते हैं) या `openself ghost` (जब तुम offline हो वह जवाब देता है)। मैंने अपना हाथ से बनाया, लेकिन बुनियादी ढाँचा वहाँ था।

सिद्धांत में, OpenSelf clone पाने के लिए अकेला काफी है, लेकिन जो कुछ मैं सुविधाएँ जोड़ने वाला था उसे देखते हुए, और चूँकि Discord समर्थित नहीं है, मैंने सिर्फ याद हिस्सा इस्तेमाल करना पसंद किया।

**और यादें और शैली कहाँ से आती हैं ?**

इन सब से पहले, मैंने अपने असली Discord संदेश विश्लेषण कराए। tooling ने दो चीजें निकालने के लिए मेरे DM और salon छाने :

1. **मेरी लेखन प्रोफाइल** - वाक्य शुरुआत में बड़े/छोटे अक्षर वितरण, प्रति संदेश emoji संख्या और उनकी स्थिति, विराम चिह्न (या उसकी अनुपस्थिति : सामान्य बातचीत में अंतिम बिंदु रहित वाक्य), औसत लंबाई, slang (`mdr`, `tkt`, `tho`), प्रिय अभिव्यक्तियाँ ("Bah", "En vrai") और `quoi` -> `Feur` तरह के reflex। यह सब `STYLE.md` में रहता है, जिसे एजेंट हर सत्र शुरुआत में पढ़ता है।
2. OpenSelf आबाद करने वाला **याद corpus** : जिन लोगों से मैं बात करता हूँ वे कौन हैं, हम किस बारे में बात करते हैं, हमारे इतिहास से क्या याद रखना है, कौन कौन है। बॉट शून्य में जवाब नहीं देता : वह उन लोगों के *बारे में* जवाब देता है जिन्हें वह "जानता" है। वह बातचीत में प्रकट लोगों की यादें पढ़ता है यह जानने के लिए कि वह कौन है। यह दूसरों पर स्थायी संदर्भ रखने, उन्हें न भूलने देता है।

बॉट ने कुछ आविष्कृत नहीं किया : वह अंक दर अंक असली पर calibrate किया गया था। इसीलिए वह सही लगता है, और अंदाजे "मैं तुम्हारी शैली नोट करता हूँ" उसके बगल में दयनीय लगते हैं।

Chlone में, OpenSelf फिर केंद्रीय भूमिका निभाता है : जब salon में कुछ महत्वपूर्ण गुजरता है (keyword "projet", "ami", "relation", या स्पष्ट माँग "याद रखो कि..."), तो बॉट `save_to_memory` से vault में याद टाइप करता है, typed, प्रति व्यक्ति scope, dedupe, संघर्षों के खिलाफ जाँचा। और जब बातचीत फिर शुरू होती है, एजेंट जवाब देने से पहले अपनी यादें खोजता है। यही दर्पण और clone के बीच अंतर है।

## शुक्रवार 11 सितंबर - दिन 1 : चिंगारी

### 11h27 - पहला बड़ा refactor

### 12h00 - reflex

STYLE में नया खंड : reflex। reflex stimulus -> उत्तर है, बिना सोचे। बेतुके उत्तरों का द्वार खुला है।

फिर दोपहर भोजन समय आता है, और अस्तित्वगत प्रश्न : क्या बॉट `Feur` जवाब देता है जब उसे `quoi` कहा जाता है ?

### 13h03 - "quoi ?" -> "Feur"

हाँ। बेशक हाँ। यह प्रोजेक्ट का सांस्कृतिक रूप से सबसे महत्वपूर्ण commit है। मैं कहूँगा : एकमात्र इकाई परीक्षण जो मायने रखता है।

फिर चिकनाई देते हैं :

- *global name* से दिखाए लेखक ;
- reflex परखने से पहले काटी विराम चिह्न (`quoi ?` काटना होगा, वरना `Feur` नहीं जाता) ;
- STYLE में प्रसिद्ध `tqt` `tkt` में सुधारा गया, जो प्रोजेक्ट नहीं जानते वे पूछेंगे कि मैं यह क्यों commit करता हूँ। मैं जानता हूँ : `tqt` लिखने वाला clone खराब calibrate clone है, और कोई खराब calibrate clone से बात नहीं करना चाहता ;
- संदर्भ में असली नामों से बदले `@123456789` उल्लेख ;
- बॉट डिफ़ॉल्ट सभी salon देखने लगता है।

## सोमवार 14 सितंबर - दिन 2 : व्यक्तित्व

- वैकल्पिक blacklist (`aventuros`) बॉट को कुछ विषयों की ओर बहने से रोकती है। डिफ़ॉल्ट निष्क्रिय, डरपोकों के लिए उपलब्ध ;
- मरी ध्वनि config हटाई गई।

### 10h12 - याद जिसका ऑडिट होता है

**मासिक याद संघर्ष sweep** + खोज A/B bench। बॉट स्मृति asset बन गई है जिसका हम निरीक्षण करते हैं। हम शुक्रवार 11, 08h24 से बहुत बहुत दूर हैं।

### 10h54 - lockdown

वह दिन जब मैं parano खेलता हूँ। एजेंट lock :

- स्मृति लेखन **अस्वीकृत** (एजेंट vault प्रदूषित नहीं कर सकता, भले ही उसे inject किया जाए) ;
- Discord उपकरण **सिर्फ पढ़ने** (भेजना कोड से गुजरता है, कभी एजेंट से नहीं) ;
- **न उप एजेंट** (lockdown दरकिनार), न webfetch (localhost SSRF, exfiltration), न headless में प्रश्न ;
- कठोर Docker : गैर root बॉट, `no-new-privileges`, `cap_drop: ALL`, स्मृति/CPU सीमाएँ, सीमित प्रक्रिया कतारें, कभी bake न किए `.env` से secret।

मैं सिद्धांत कोड में टिप्पणी में लिखता हूँ : *"मानवीय सत्रों से dev, यहाँ नहीं"*।
