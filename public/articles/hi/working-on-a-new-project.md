# प्रोजेक्ट

जिस प्रोजेक्ट पर मैं काम कर रहा हूँ उसे LLJT कहा जाता है:

![](assets/20260313_092734_image.png)

यह एक वेबसाइट है जो एक PWA भी है, इसलिए एक मोबाइल एप्लिकेशन भी है। यह एक वास्तविक फ़ोन एप्लिकेशन का अहसास देने के लिए MaterialUI का उपयोग करता है।
मुझे हाल ही में Mui इम्पोर्ट को संभालना पड़ा, और मैं 11707 मॉड्यूल से घटकर केवल 595 पर आ गया, प्रत्येक आइकन को मैन्युअल रूप से लाइन दर लाइन इम्पोर्ट करके, बजाय डी-स्ट्रक्चर्ड इम्पोर्ट का उपयोग करने के: मैंने सीखा कि जब आप डी-स्ट्रक्चर्ड इम्पोर्ट करते हैं, तो आप वास्तव में पूरी आइकन लाइब्रेरी लोड कर लेते हैं, जबकि उन्हें व्यक्तिगत रूप से इम्पोर्ट करने पर, आप केवल वही इम्पोर्ट करते हैं जिनकी आपको आवश्यकता है।

Nibi वह बॉट है जो इस वेबसाइट से जुड़ा है।![](assets/20260313_093102_image.png) ग्रेडिंग Google Forms पर आधारित है:
![](assets/20260313_093255_image.png)
हम अपने छात्रों का मूल्यांकन करने के लिए MCQ का उपयोग करते हैं, और यदि वे कोई महत्वपूर्ण परीक्षा पास करते हैं तो हम अपने छात्रों को Discord भूमिकाएँ, साथ ही इमोजी और चैनल भी देते हैं।

![](assets/20260313_093707_image.png)

इस प्रोजेक्ट का उद्देश्य लोगों को हमारे साथ मिलकर जापानी सीखने में मदद करना है, क्योंकि मैं भी खुद ऐसा करना चाहता हूँ।
छात्र उनके कौशल को पुरस्कृत करने के लिए Crunchyroll और अन्य प्लेटफ़ॉर्म के साथ पार्टनरशिप भी अनलॉक करेंगे।

Nibi और साइट क्रमशः Cloudflare Workers (Hono Server के साथ URL Interaction) और GitHub Pages React के साथ होस्ट किए गए हैं।
साइट का कोड ओपन सोर्स नहीं है, लेकिन Nibi है, और आप इसे [इस GitHub रिपॉजिटरी](https://github.com/let-s-Learn-Japanese-Together/nibi) पर पा सकते हैं। साइट ओपन सोर्स नहीं है क्योंकि इसमें निजी जानकारी है, लेकिन अगर आप जानना चाहते हैं कि मैंने इसे कैसे बनाया, तो आप मुझसे Discord या अन्य माध्यम से पूछ सकते हैं, और मुझे आपके साथ प्रक्रिया साझा करने में खुशी होगी! यह वास्तव में एक GitHub Action का उपयोग करता है जिसे मैंने GitHub Enterprise के लिए भुगतान न करने के लिए बनाया था, और यह कई अन्य शानदार टूल और तकनीकों का भी उपयोग करता है जिन्हें मैं आपके साथ साझा कर सकता हूँ यदि आपको रुचि हो!

पिछले कुछ दिनों से, मुझे वास्तव में अपने प्रोजेक्ट्स को होस्ट करने और उनके होस्टिंग के लिए भुगतान करने से बचने के लिए वर्कअराउंड ढूँढ़ना पसंद आ रहा है। यही कारण है कि मैंने Nibi को एक Interaction Endpoint बॉट बनाया, ताकि इसे Cloudflare Workers पर मुफ्त में होस्ट किया जा सके, और मैंने साइट को GitHub Pages पर मुफ्त में डिप्लॉय करने के लिए एक GitHub Action भी बनाई, ताकि इसकी होस्टिंग के लिए भुगतान न करना पड़े। मुझे लगता है कि वर्कअराउंड ढूँढ़ना कोडिंग के सबसे मजेदार हिस्सों में से एक है, और यह एक ऐसी चीज़ है जिसका मैं बहुत आनंद लेता हूँ! वास्तव में बॉक्स के बाहर सोचना और समस्याओं के रचनात्मक समाधान ढूँढ़ना होता है, और यही मुझे पसंद है। यह केवल कोड लिखने का सवाल नहीं है, बल्कि पैसे खर्च किए बिना चीज़ों को काम करने के तरीके खोजने का है, और यह एक ऐसी चुनौती है जिसकी मैं वास्तव में सराहना करता हूँ!

GitHub Actions का इस तरह से उपयोग करना जो विशेष रूप से इसके लिए नहीं बनाया गया है, और Cloudflare Workers का उपयोग करके एक बॉट को "होस्ट" करना, नई चीज़ें सीखने और नई तकनीकों की खोज करने का भी एक तरीका है, जैसे क्लाउड होस्टिंग, जिसकी मैं भी सराहना करता हूँ। मैं वास्तव में अब होस्टिंग के लिए भुगतान नहीं करना चाहता।

मैं अभी भी इस पर काम कर रहा हूँ लेकिन आप [Discord सर्वर](https://discord.gg/frKZ9cJ4fD) में शामिल हो सकते हैं यदि आप प्रगति का अनुसरण करना चाहते हैं और देखना चाहते हैं कि यह कैसे विकसित हो रहा है, और शायद प्रोजेक्ट में शामिल भी हो सकते हैं यदि आपको रुचि हो! सर्वर सभी के लिए खुला है, और हम जापानी सीखने की इस यात्रा में हमारे साथ शामिल होने के लिए और अधिक लोगों को पाकर खुश होंगे! आप साइट पर आमंत्रण लिंक पा सकते हैं, या आप मुझसे पूछ सकते हैं यदि आप चाहें!
