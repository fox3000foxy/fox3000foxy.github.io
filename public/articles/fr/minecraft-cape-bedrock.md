Saviez-vous qu'il est techniquement possible d'équiper presque n'importe quelle cape officielle dans Minecraft Bedrock ? Cela peut sembler trop beau pour être vrai, mais grâce à une ancienne version buguée de Minecraft, c'est tout à fait possible !

Voici comment procéder, étape par étape.

\## Préparer Bedrock Launcher

Pour réaliser cette manipulation, vous ne pouvez pas utiliser la version classique du jeu. Vous devrez utiliser une ancienne version de Minecraft.

1\. \*\*Téléchargez Bedrock Launcher Lite\*\* depuis le \[dépôt GitHub officiel\]([https://github.com/bedrockLauncher/BedrockLauncher/](https://github.com/bedrockLauncher/BedrockLauncher/)).

2\. \*\*Activez le mode développeur de Windows\*\* dans les paramètres de Windows (nécessaire pour que le launcher puisse enregistrer les anciennes versions).

3\. \*\*Installez Microsoft Visual C++ Redistributable\*\* si le launcher vous le demande.

\> \*\*Remarque :\*\* Assurez-vous d'avoir installé et lancé Minecraft Bedrock au moins une fois depuis le \[Launcher officiel de Minecraft\]([https://www.minecraft.net/download](https://www.minecraft.net/download)) avant de continuer.

\## Le bug des capes

Une fois votre launcher prêt, suivez les étapes suivantes :

1\. Ouvrez \*\*Bedrock Launcher\*\*, rendez-vous dans l'onglet \*\*Configurations\*\*, puis lancez la version \*\*1.16.0.2\*\* de Minecraft Bedrock.

2\. Ouvrez l'\*\*éditeur de skins\*\* et créez un \*\*nouveau\*\* personnage avec le \*\*Créateur de personnage\*\*. \*\*Ne modifiez pas\*\* son apparence pour le moment.

3\. Ouvrez l'onglet \*\*Capes\*\*, sélectionnez la cape de votre choix, puis revenez au menu principal des skins et attendez l'apparition de la notification \*\*`[Skin Saved]`\*\*.

4\. Fermez le jeu.

5\. Désinstallez complètement Minecraft Bedrock.

6\. Réinstallez Minecraft Bedrock normalement à l'aide du \*\*Launcher officiel de Minecraft\*\*.

🎉 \*\*Et voilà !\*\* Au prochain lancement de Minecraft Bedrock, votre personnage portera la cape sélectionnée. Vous pourrez ensuite personnaliser le reste de votre personnage sans perdre la cape.

\## Restrictions importantes

Avant de rejoindre une partie multijoueur, gardez les limitations suivantes à l'esprit.

\### Les skins personnalisés ne fonctionnent pas

Ce bug fonctionne uniquement avec les personnages créés à l'aide du \*\*Créateur de personnage\*\* intégré au jeu. Si vous utilisez un skin personnalisé au format \*\*`.png`\*\*, la cape ne sera pas visible par les autres joueurs.

\### Les serveurs officiels

Cette méthode ne fonctionne \*\*pas\*\* sur les serveurs officiels ou partenaires, comme \*\*The Hive\*\*, \*\*CubeCraft\*\*, etc. Ces serveurs utilisent leur propre système de skins, qui remplace les cosmétiques du Créateur de personnage et désactive les capes.
