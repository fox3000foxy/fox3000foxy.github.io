# المشروع

المشروع الذي أعمل عليه اسمه LLJT :

![](assets/20260313_092734_image.png)

إنه موقع ويب وهو أيضا PWA، أي قابل للاستخدام كتطبيق هاتف. يستخدم MaterialUI ليتصرف كتطبيق هاتف حقيقي.
قضيت بعض الوقت على واردات Mui : انتقلت من 11707 وحدة إلى 595 في النهاية، باستيراد كل أيقونة سطرا بسطر بدلا من الاستيراد المفكك. تعلمت حينها أن الاستيراد المفكك يحمّل مكتبة الأيقونات كاملة، بينما الاستيرادات الفردية لا تحمّل إلا المستخدم منها.

Nibi هو البوت المتصل بهذا الموقع.![](assets/20260313_093102_image.png)التقييم يعتمد على Google Forms :
![](assets/20260313_093255_image.png)
نستخدم اختبارات QCM لتقييم طلابنا، ونمنح أيضا أدوار Discord وإيموجي وقنوات لطلابنا عندما ينجحون في امتحان مهم.

![](assets/20260313_093707_image.png)

هدف هذا المشروع هو مساعدة الناس على تعلم اليابانية معا معنا، لأن هذا شيء أريد فعله بنفسي أيضا.
سيفتح الطلاب أيضا شراكات مع Crunchyroll ومنصات أخرى، لمكافأة تقدمهم.

Nibi والموقع مستضافان على التوالي بواسطة Cloudflare Workers (Interaction URL مع Hono Server) وGitHub Pages مع React.
كود الموقع ليس مفتوح المصدر، لكن Nibi مفتوح، ويمكنك إيجاده على [مستودع GitHub هذا](https://github.com/let-s-Learn-Japanese-Together/nibi). الموقع يبقى خاصا لأنه يحتوي على معلومات خاصة، لكن إذا أردت معرفة كيف بنيته، اسألني على Discord وسأشرح لك العملية بسرور ! يستخدم GitHub Action أنشأتها لتجنب دفع GitHub Enterprise، بالإضافة إلى عدة أدوات وتقنيات أخرى يمكنني أن أصفها لك إذا كان ذلك يهمك !

منذ أيام، أستمتع كثيرا بإيجاد حلول بديلة لاستضافة مشاريعي دون دفع استضافة. لهذا جعلت Nibi بوت Interaction Endpoint، لاستضافته مجانا على Cloudflare Workers، وأنشأت GitHub Action لنشر الموقع مجانا على GitHub Pages. البحث عن هذه الحلول البديلة يبقى بالنسبة لي من أكثر أجزاء البرمجة إثارة : يجب التفكير بشكل مختلف وبناء حلول إبداعية، وهذا التحدي بدون ميزانية هو بالضبط ما يحفزني !

استخدام GitHub Actions خارج استعماله المقصود، واستخدام Cloudflare Workers "لاستضافة" بوت، هو أيضا طريقة لتعلم أشياء جديدة واكتشاف تقنيات جديدة، مثل الاستضافة السحابية. لم أعد أريد الدفع مقابل الاستضافة.

ما زلت أعمل عليه لكن يمكنك الانضمام إلى [سيرفر Discord](https://discord.gg/frKZ9cJ4fD) إذا أردت متابعة التقدم ورؤية كيف يتطور، وربما حتى الانضمام إلى المشروع إذا كان ذلك يهمك ! السيرفر مفتوح للجميع، ونود أن يكون معنا المزيد من الناس لتعلم اليابانية معا ! ستجد رابط الدعوة على الموقع، أو يمكنك أن تطلبه مني مباشرة !
