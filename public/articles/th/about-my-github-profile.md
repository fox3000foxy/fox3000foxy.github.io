# โปรไฟล์ GitHub ของฉัน

## หัวเรื่อง & ลิงก์

ยินดีต้อนรับสู่โปรไฟล์ GitHub ของฉัน -- จัดระเบียบเหมือนห้องสมุดที่เป็นระเบียบเรียบร้อย
ในส่วนแรกจะมีหัวเรื่องพร้อมลิงก์ ค่อนข้างมาตรฐานก็ว่าได้ :
![](assets/20260308_123527_image.png)

อย่างที่เห็น ก็มีลิงก์ เท่มากนะฉันว่า ก็ไม่รู้จะพูดอะไรเพิ่มเติม

## เกี่ยวกับฉัน

นอกจากนี้ยังมีส่วน "เกี่ยวกับฉัน" ด้วย :

![](assets/20260308_123913_image.png)

ในส่วนนี้คุณสามารถดูสิ่งที่ฉันกำลังทำแบบสด ๆ ! ถ้าคุณเห็นฉันกำลังฟังเพลง นั่นแหละคือสิ่งที่ฉันทำ
ฉันจะใส่ indicator ไว้ตรงนี้ด้วย :

## โปรเจกต์
ด้านล่างฉันมี repository ทั้งหมดของฉันจัดหมวดหมู่ไว้ อย่าลังเลที่จะเข้าไปดูถ้าสนใจ -- บอกไว้ก่อนว่าเกือบทุกโปรเจกต์จะมีบทความของตัวเอง :

![](assets/20260308_145026_image.png)

## สรุป

นี่คือโปรไฟล์ GitHub ของฉัน หวังว่าการเยี่ยมชมครั้งนี้จะถูกใจนะ ! ฉันอาจจะเขียนบทความสำหรับแต่ละโปรเจกต์ ดังนั้นคอยติดตามไว้ หากมีคำถามหรืออยาก collaborate ด้วยกัน อย่าลังเลที่จะติดต่อฉันทาง Discord หรือ GitHub ขอบคุณที่แวะมา !
