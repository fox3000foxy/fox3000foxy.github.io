# โปรไฟล์ GitHub ของฉัน

## หัวเรื่อง & ลิงก์

ยินดีต้อนรับสู่โปรไฟล์ GitHub ของฉัน ที่จัดเรียงเป็นห้องสมุดที่เรียบร้อยดี  
ในส่วนแรกมีหัวเรื่องพร้อมลิงก์ รูปแบบที่ค่อนข้างมาตรฐานที่ฉันพบว่าเป็นประโยชน์ในการชี้แนวตั้งแต่เริ่มเข้า:  
![](assets/20260308_123527_image.png)

คุณจะเห็นลิงก์หลักของฉันไปยังโปรเจกต์ของฉัน การติดต่อ และเว็บไซต์นี้ ฉันรวบรวมไว้บนสุดเพื่อให้คุณเข้าถึงสิ่งสำคัญโดยตรงโดยไม่ต้องค้นหาในรีโพ  

## เกี่ยวกับฉัน

ยังมีส่วน "เกี่ยวกับฉัน":  
![](assets/20260308_123913_image.png)

ในส่วนนี้คุณจะเห็นว่าฉันกำลังทำอะไรแบบสดถ้าคุณเห็นฉันฟังเพลง ฉันอาจกำลังเขียนโค้ดพร้อมพัซเกจเพลงอยู่เบื้องหลัง  
ฉันใส่ตัวบ่งชี้ที่นี่เช่นกัน:  

### สถานะสตรีมสด  
[![สถานะ Discord](https://lanyard.cnrad.dev/api/724847846897221642?showDisplayName=true)](https://discord.com/users/724847846897221642)

## โครงการ
ด้านล่างฉันมีแหล่งเก็บทั้งหมดของฉันจัดตามประเภท ก็มองดูหากคุณสนใจโดเมนใด ฉันวางแผนเขียนบทความบล็อกสำหรับเกือบทุกตัวของพวกเขา:

![](assets/20260308_145026_image.png)

## สรุป
นี่คือโปรไฟล์ GitHub ของฉัน ฉันหวังว่าการเยี่ยมชมจะทำให้คุณชอบ ฉันจะเขียนบทความสำหรับแต่ละโครงการของฉัน ดังนั้นมาคืนมาเป็นระยะ ๆ หากคุณมีคำถามหรืออยากร่วมงานบางอย่าง ติดต่อฉันผ่าน Discord หรือ via GitHub ขอบคุณสำหรับการเยี่ยมชม!
