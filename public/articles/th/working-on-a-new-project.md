# โปรเจกต์

โปรเจกต์ที่ฉันกำลังทำอยู่ชื่อ LLJT:

![](assets/20260313_092734_image.png)

มันเป็นเว็บไซต์ที่ยังเป็น PWA ด้วย ดังนั้นจึงเป็นแอปมือถือด้วยเหมือนกัน มันใช้ MaterialUI เพื่อให้รู้สึกเหมือนเป็นแอปโทรศัพท์จริง ๆ
เมื่อเร็ว ๆ นี้ฉันต้องจัดการกับ imports ของ Mui และ我从 11707 modules เหลือเพียง 595 ในตอนท้าย โดยการ import แต่ละไอคอนด้วยตนเองทีละบรรทัด แทนที่จะใช้ destructured import: ฉันได้เรียนรู้ว่าเมื่อเราใช้ destructured import เรากำลังโหลดทั้งไลบรารีไอคอน ในขณะที่ถ้า import ทีละตัว เราจะ import เฉพาะที่ต้องการเท่านั้น

Nibi คือบอทที่เชื่อมต่อกับเว็บไซต์นี้
![](assets/20260313_093102_image.png)
การวัดระดับอิงจาก Google Forms:
![](assets/20260313_093255_image.png)
เราใช้ข้อสอบแบบปรนัย (QCM) เพื่อประเมินนักเรียนของเรา และเรายังให้ roles ใน Discord รวมถึง emojis และห้องแชท แก่นักเรียนของเรา หากพวกเขาสอบผ่านที่สำคัญ

![](assets/20260313_093707_image.png)

เป้าหมายของโปรเจกต์นี้คือการช่วยให้ผู้คนเรียนภาษาญี่ปุ่นไปพร้อมกับเรา เพราะนั่นเป็นสิ่งที่ฉันอยากทำด้วยตัวเองเช่นกัน
นักเรียนจะปลดล็อกความร่วมมือกับ Crunchyroll และแพลตฟอร์มอื่น ๆ เพื่อเป็นรางวัลสำหรับทักษะของพวกเขา

Nibi และเว็บไซต์โฮสต์โดย Cloudflare Workers (Interaction URL กับ Hono Server) และ GitHub Pages กับ React ตามลำดับ
โค้ดของเว็บไซต์ไม่ได้เป็น open source แต่ Nibi เป็น และคุณสามารถหาได้ที่ [GitHub repository นี้](https://github.com/let-s-Learn-Japanese-Together/nibi) เว็บไซต์ไม่ได้เป็น open source เพราะมันมีข้อมูลส่วนตัว แต่ถ้าคุณอยากรู้ว่าฉันสร้างมันขึ้นมาได้อย่างไร คุณสามารถถามฉันผ่าน Discord หรือช่องทางอื่นได้ และฉันยินดีแบ่งปันกระบวนการให้คุณฟัง! จริง ๆ แล้วมันใช้ GitHub Action ที่ฉันสร้างขึ้นเพื่อไม่ต้องจ่ายค่า GitHub Enterprise และยังใช้เครื่องมือและเทคนิคเจ๋ง ๆ อีกมากมายที่ฉันสามารถแชร์ได้ถ้าคุณสนใจ!

ไม่กี่วันที่ผ่านมา ฉันชอบหาวิธีเลี่ยงเพื่อไม่ต้องโฮสต์โปรเจกต์ของตัวเองและไม่ต้องจ่ายค่าโฮสต์ นั่นเป็นเหตุผลที่ฉันทำให้ Nibi เป็น Interaction Endpoint Bot เพื่อให้มันโฮสต์ฟรีบน Cloudflare Workers และฉันยังสร้าง GitHub Action เพื่อ deploy เว็บไซต์ฟรีบน GitHub Pages เพื่อไม่ต้องจ่ายค่าโฮสต์ ฉันคิดว่าการหาวิธีเลี่ยงปัญหานี้เป็นหนึ่งในส่วนที่สนุกที่สุดของการเขียนโค้ด และเป็นสิ่งที่ฉันชอบมาก! คุณต้องคิดนอกกรอบและหาวิธีแก้ไขปัญหาอย่างสร้างสรรค์ และนั่นคือสิ่งที่ฉันรัก มันไม่ใช่แค่เรื่องของการเขียนโค้ด แต่มันคือการหาวิธีทำให้สิ่งต่าง ๆ ทำงานได้โดยไม่ต้องใช้เงิน และนั่นคือความท้าทายที่ฉันชอบจริง ๆ!

การใช้ GitHub Actions ในแบบที่ไม่ใช่จุดประสงค์หลัก และการใช้ Cloudflare Workers เพื่อ "โฮสต์" บอท ก็เป็นวิธีการเรียนรู้สิ่งใหม่ ๆ และค้นพบเทคโนโลยีใหม่ ๆ เช่น cloud hosting ซึ่งฉันก็ชอบเช่นกัน ฉันไม่อยากจ่ายค่าโฮสต์อีกต่อไปแล้ว

ฉันยังคงทำงานอยู่ แต่คุณสามารถเข้าร่วม [Discord Server](https://discord.gg/frKZ9cJ4fD) ได้ถ้าคุณอยากติดตามความคืบหน้าและดูว่ามันพัฒนาไปอย่างไร และอาจจะร่วมโปรเจกต์ด้วยถ้าคุณสนใจ! เซิร์ฟเวอร์เปิดให้ทุกคน และเราอยากให้มีคนมากขึ้นมาร่วมเดินทางไปกับเราในการเรียนภาษาญี่ปุ่นไปด้วยกัน! คุณสามารถหาลิงก์เชิญได้บนเว็บไซต์ หรือคุณสามารถถามฉันได้ถ้าต้องการ!
