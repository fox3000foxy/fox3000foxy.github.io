# ความหลงใหลของฉัน

ฉันอยากเขียนบล็อกนี้มานานแล้ว แต่ก็หยุดตัวเองไว้เรื่อยเลย :/

บางทีอาจเป็นเพราะฉันอยากแบ่งปันชีวิตแต่ไม่อยากแชร์ข้อมูลส่วนตัว? ฉันเดาว่านั่นคือสาเหตุ

## การเขียนโค้ด

ความหลงใหลของฉันมีหลากหลาย: ฉันชอบเขียนโค้ด อย่างที่คุณคงสังเกตเห็นจากส่วนอื่นของบล็อกนี้ มันมีความรู้สึกพึงพอใจอย่างลึกซึ้มในการสร้างสิ่งต่างๆจากศูนย์ การแก้ปัญหา และการได้เห็นผลงานของตัวเองมีชีวิตขึ้นมา ไม่ว่าจะเป็นเครื่องมือบรรทัดคำสั่งเล็กๆ หรือเว็บแอปพลิเคชันเต็มรูปแบบ กระบวนการนี้ไม่เคยล้าสมัย

ฉันมีความรักเป็นพิเศษกับ **โอเพนซอร์ส** -- การแบ่งปันคือการให้ และฉันซาบซึ้งอย่างจริงใจกับความคิดที่ว่าคนอื่นจะพบว่าโค้ดของฉันมีประโยชน์ โปรเจกต์ส่วนใหญ่ของฉันอยู่บน [GitHub ของฉัน](https://github.com/fox3000foxy) และคุณสามารถชมได้ที่ [หน้าโปรเจกต์](/projects)

## ทำให้ทุกอย่างที่ขยับเป็นอัตโนมัติ

ฉันยังหลงใหลในการทำให้เป็นอัตโนมัติ การเล่นกับ GitHub Actions และ workflows เป็นหนึ่งในความรู้สึกที่ดีที่สุดที่ฉันเคยมี เมื่อไหร่ก็ตามที่ฉันสามารถแทนที่กระบวนการที่ทำด้วยมือด้วยสคริปต์หรือไปป์ไลน์ ฉันจะทำทันที -- โดยไม่ลังเล

ฉันเพิ่งเริ่มเซ็น commit ด้วยคีย์ SSH และได้ทำสคริปต์ไว้ให้คุณดูได้ที่ [gist นี้](https://gist.github.com/fox3000foxy/95500d129cd4bf5c173c323d2492569a)

## การค้นพบเทคโนโลยีเก่าๆ

ฉันชอบค้นพบเทคโนโลยีเก่าๆ เช่น UTAU -- ฉันพบว่าแนวคิดนี้ค่อนข้างน่าหลงใหล มันมีบางอย่างที่พิเศษในการทำความเข้าใจว่าผู้คนสร้างสิ่งต่างๆ ก่อนยุคสมัยใหม่ของ AI และคลาวด์คอมพิวติ้งได้อย่างไร

## Vtubers

ฉันยังชอบ Vtubers และอยากเป็นหนึ่งในนั้นสักวัน แต่โชคไม่ดีที่ฉันค่อนข้างขี้อาย บางทีสักวัน!

## ดนตรี

งานอดิเรกหลักของฉันคือการเขียนโค้ดไปพร้อมกับฟังเพลง ไม่มีอะไรดีไปกว่าการเข้าสู่สภาวะ flow กับเพลย์ลิสต์ที่ใช่ ตอนนี้ฉันก็เริ่มชอบเดินมากขึ้นด้วย ไม่รู้ว่าทำไม 😕

## การหาทางเลี่ยง

ฉันยังชอบหาทางเลี่ยงเพื่อไม่ต้องจ่ายเงินสำหรับบางสิ่ง -- หรืออย่างน้อยก็คิดนอกกรอบ ตัวอย่างเช่น [Nibi](https://github.com/Let-s-Learn-Japanese-Together/Nibi) เป็นหนึ่งในผลงานล่าสุดของฉันที่ฉันหาวิธีฟรีสำหรับการจัดการคำสั่งซื้อ การจัดการฐานข้อมูล และ daemon มันไม่ใช่เรื่องของความขี้เหนียว -- มันคือความท้าทายต่างหาก!

## ทำไมบล็อกนี้

ฉันอยากให้บล็อกนี้เป็นพื้นที่ที่ฉันสามารถแบ่งปันความก้าวหน้า ความคิด และทุกอย่างที่ฉันอยากแชร์ เพื่อที่คุณจะได้รู้ว่าฉันคิดอย่างไร และการเขียนเกี่ยวกับความหลงใหลของฉันดูเหมือนจะเป็นวิธีที่สมบูรณ์แบบในการเริ่มต้น

ขอบคุณที่อ่าน!
