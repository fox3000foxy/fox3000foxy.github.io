## 引言

![瞄准火箭发射器的 TF2 士兵机器人](assets/tf2-bot-ai-soldier-aim.png)

每个 TF2 玩家至少说过一次："这个机器人作弊了。"或者相反："为什么这个简单机器人就站在那里吃火箭。"没人真正知道"简单"、"普通"、"困难"和"专家"在底层到底意味着什么----Valve 发布了四个难度标签和零个文档。

所以我们一群人（我、awimii、Mush The Possum，以及完成了大量基础工作的 sigsegv，他实际上去翻阅了反编译的游戏代码）整理了一份关于 TFBot 行为的完整研究文档。每一个机制、每一个已知的 Bug、每一个硬编码的概率。这篇文章是完整版，不是精简版。拿好 Bonk 饮料，这会很长。

## 第一章：基础

### 机器人 vs 傀儡机器人

TF2 有两种完全不同但都被称为"机器人"的东西：

- **AI 机器人（TFBots）**：真正的 AI，基于 Valve 用于《Left 4 Dead》系列的同一 PlayerBot/Infected 框架构建。它们随机选择职业，执行目标，无需 `sv_cheats` 即可工作，并且像真实玩家一样触发成就。
- **傀儡机器人**：没有 AI，无法自行移动或行动。它们纯粹为了手动控制而存在----玩家可以强制它们跟随、瞄准和开火，主要用于测试或制作电影截图/视频。生成它们需要 `sv_cheats 1`，这也会在该会话中禁用成就。

本文完全关于第一种。

### AI 机器人（大致）可以被告知做什么

TFBots 不能直接控制，但有一小部分事情你可以引导它们去做：

- 将你的准星对准任何机器人（友方或敌方），如果你使用正确的语音绑定，它会对你做出嘲讽动作。
- 如果你使用"Medic！"语音命令，友方医疗兵机器人会治疗你。
- 如果医疗兵机器人正在治疗你并且有 ÜberCharge 准备就绪，说"Go go go！"或"Activate charging！"会让它立即释放充能。
- 有充能就绪的医疗兵机器人会在它或它的治疗目标受到严重伤害时自动释放充能，无需语音命令。
- 机器人会自发地与附近的队友进行搭档嘲讽（击掌）或群体嘲讽（康加舞）。

### 让机器人在不支持的地图上工作

机器人依赖导航网格来知道它们可以走到哪里，大多数社区地图没有附带导航网格。要强制生成：

1. `sv_cheats 1`
2. `nav_generate`----构建初始导航网格，进度显示在控制台中
3. 等待游戏完成路径生成
4. 可选：使用 `nav_edit 1` 手动修复错误的导航数据
5. 重新加载或重启服务器（跳过此步骤会禁用成就）
6. `tf_bot_add <数量>` 来实际生成机器人

**警告：** 在机器人活跃于服务器上时更改导航网格可能会导致游戏崩溃。一旦网格存在，你在以后的会话中不需要重新生成它----只需使用 `tf_bot_add` 重新添加机器人即可。

自动生成的网格在控制点、山丘之王、推车和夺旗模式地图上效果最好。在魔力模式地图上，机器人默认采用夺旗模式的行为方式，但几乎不使用抓钩或强化道具。如果地图没有机器人 AI 能识别的目标，但确实有出生区域实体，设置 `tf_bot_offense_must_push_time 0` 可以让机器人照常战斗。

*（本节来源：TF2 官方 Wiki 的机器人页面。）*

### 当前状态，逐个地图

多亏了 Hatless 更新，现在每个职业都能正常工作，包括历来 Bug 最多的间谍。机器人在大多数官方 KOTH 地图、一些推车地图、Dustbowl/Gorge 攻防战地图以及夺旗/Mann Manor 地图上表现正常----不过在后者中你不能直接用 `tf_bot_add` 生成它们。在不受支持的地图上（通过上述 nav_generate 流程）它们也能工作，只是模仿真实玩家的效果明显较差。

PLR 地图则是无药可救的：机器人无法清除 Hightower 上的屏障并且会卡在角落里，而在所有其他 PLR 地图上，它们只是……开舞会而不是玩游戏。这也许最终会被修复。也许不会。

### 机器人一般行为

每个机器人都会做的一系列杂项事情，与技能无关：

- 机器人只使用默认装备（插件可以强制它们使用非默认武器，但原版机器人从不自己选择）。
- 简单机器人几乎不使用副武器。更高难度的机器人在主武器弹药耗尽时会立即切换到副武器，或者为了补偿射程而切换。
- 机器人不会做移动技巧----没有火箭跳，没有建筑搬迁。
- 击杀后，机器人可能会嘲讽，即使正在被攻击----携带敌方情报时除外，这一条规则也适用于 MvM 模式。
- 伪装的间谍机器人（玩家或 AI）会被其他机器人正确忽略----直到它们碰到敌人、破坏某物、开枪或在附近隐形。一旦"暴露"，该特定机器人/玩家会被记住为间谍，直到它在保持隐形的状态下更换伪装、死亡或用 Dead Ringer 假死。
- 火焰兵机器人在简单以上难度会大量使用压缩爆。
- 医疗兵机器人优先治疗除狙击手（以及在较小程度上，工程师）之外的所有人，即使你作为这些职业拼命喊"Medic！"。
- 医疗兵机器人倾向于靠近机枪手、士兵、爆破手和火焰兵----特别是如果有*人类*在玩这些职业。如果没有人类扮演这些角色，医疗兵不会特别关注。
- 机器人在攻防战和推车地图的备战期间会原地待命----但工程师、狙击手和间谍除外，它们可以自由移动（爆破手机器人也允许预先放置粘性炸弹）。
- 工程师机器人从不升级或解除其他友好工程师建筑上的敌意侵蚀，除非该建筑恰好挡住了它们的路径。它们有时也……就是不去修理自己的炮塔，即使在安全的情况下。
- 被发现行踪的间谍机器会切换到左轮手枪并后退，而不是强行背刺。
- 已经定位到步哨枪（通常是通过被它杀死一次）的爆破手机器人可以完美地从步哨枪射程外曲射粘性炸弹，在几何条件允许时绕过墙壁和天花板弧线飞行。
- 找不到目标的狙击手机器人瞄准后会说出一句"否定"语音台词。
- 友方医疗兵会毫不犹豫地治疗伪装的间谍。

### 已知问题 / Bug

文档列出了大量长期存在的怪癖：

- 机器人可能试图穿过某些静止的道具行走或射击。
- 每当玩家/机器人解除伪装、伪装或暴露时，附近的机器人会"看到"它并转身做出反应----即使该事件发生在它们实际的视野之外。这不是基于声音的；这是一个视觉检查绕过。
- 罕见情况下，机器人会在使用工程师传送器时物理卡在一起。
- 机器人的语音命令（例如"Spy！"、"Forward！"）不会像玩家那样以聊天文本显示。
- 正在积极治疗他人的医疗兵机器人不会躲避来袭火力或拾取血包，即使在血量极低时。
- 机器人可以在执行搭档嘲讽时继续移动，这破坏了节日暴击的预期效果。
- 最近受伤的医疗兵机器人在远处通常拒绝使用注射枪，而更喜欢近战武器（或者在极少数情况下，试图直接用医疗枪束打你）。
- 医疗兵机器人不会补偿注射枪射击的重力下落----可能是因为该武器在 AI 代码中没有被正确标记为非 hitscan 武器。
- 间谍机器人可以看到和追踪隐形的间谍（玩家或 AI），如果该间谍已经暴露过一次，无论追踪机器人的技能水平如何。
- 即使玩家间谍伪装成自己队伍的职业，撞到敌人仍然会暴露他们（机器人从不这样对自己，因为机器人从不伪装成自己的队伍）。
- 机器人遵守队伍自动平衡----如果你试图在一方队伍堆叠机器人，你需要先设置 `mp_teams_unbalance_limit 0`。
- 工程师机器人可能完全无视自己的建筑，直到它们被摧毁。
- 机枪手机器人有时会在弹药极低时试图开火，主要在困难难度以下。
- 失败一方的医疗兵机器人在羞辱阶段附近没有敌人时偶尔会自杀----这是人类玩家即使试图模仿也无法复制的行为。
- 将加载界面队伍预览设置为 BLU 会使 RED 机器人在视觉上为你渲染为 BLU。
- 装备近战武器的机器人有时在拾取弹药后拒绝切换武器。
- Jungle Inferno 更新后，使用显式参数生成的机器人（例如 `tf_bot_add 5 pyro blue normal`）可能会在自己的出生室立即死亡。修复：`tf_bot_reevaluate_class_in_spawnroom 0`（需要 `sv_cheats 1`）。

### AI 名称

机器人名称来自一个庞大的引用池，涉及 TF2、其他 Valve 游戏和编程文化，主要是因为社区一直在 Steam 论坛上要求特定的名称。列表的一部分示例：*AimBot、Aperture Science Prototype XR7、Black Mesa、Companion Cube、C++、Divide by Zero、GLaDOS、H@XX0RZ、Saxton Hale、The G-Man、trigger_hurt、0xDEADBEEF*，以及几十个类似的名称。

还有一批名称来自一个泄露的源代码构建版本，从未在生产环境中发布，原因不明----主要是《最后的龙》和《第五元素》的引用，如 *John Spartan、Leeloo Dallas Multipass、Sho'nuff、Bruce Leroy、Big Gulp Huh？* 和 *I'm your huckleberry*。

你也可以自己覆盖所有这些：`tf_bot_add heavyweapons blue "Blu Hoovy"` 会生成一个名为"Blu Hoovy"的蓝队机枪手。

## 第二章：原始机器人 / TFBots----技能深度解析

Sigsegv 的原始框架仍然成立：专家机器人明显比简单机器人强，但 Valve 从未解释过*多少*或*为什么*。所以唯一的方法是阅读代码。以下是每个随技能变化的机制。

### 设置难度

在 MvM 模式之外，难度由一个 cvar 控制：

| `tf_bot_difficulty` | 技能等级 |
| --- | --- |
| 0 | 简单 |
| 1 | 普通（默认） |
| 2 | 困难 |
| 3 | 专家 |

`tf_bot_add` 也直接接受一个难度参数（`easy`/`normal`/`hard`/`expert`）。

### MvM 配置文件

在 Mann vs. Machine 模式中，配置文件中的每个 `TFBot` 生成器块都有一个可选的 `Skill` 键。没有键则默认为简单。在 Valve 自己的任务中：巨人几乎总是专家，工程师和间谍几乎总是专家，狙击手通常是困难（偶尔是专家）。如果你使用 `EventChangeAttributes`（在 Two Cities 更新中添加）来根据地图事件动态变化机器人的属性，机器人技能是你可以在运行中更改的属性之一。

### MvM 无尽模式

无尽模式从未正式发布，但在其中，机器人会像玩家一样花钱升级----包括一个机器人专属的升级，可以在游戏中期提升它们的 AI 技能等级。

### `bot_generator` 实体

一个晦涩的、基本没有文档的实体，被认为曾在训练模式中使用过，可能也在早期的 MvM 开发中使用过。它暴露了一个 `SetDifficulty` 输入来控制技能等级。除此之外，线索就断了----Valve 从未记录过它，也没有人完全弄清其行为。

### 眼睛发光颜色

MvM 机器人有一个随技能等级变化颜色的眼睛发光粒子----社区以外没有人解释过的视觉提示：

| 技能 | 眼睛颜色 | RGB |
| --- | --- | --- |
| 简单/普通 | 蓝色 | `#24b4ff` |
| 困难/专家 | 黄色 | `#fff000` |

![待机姿态的 TF2 机枪手机器人](assets/tf2-bot-ai-heavy-idle.png)

### 视觉：识别时间

机器人不会在物体进入其视野的瞬间做出反应----在 AI 被允许确认威胁之前有一个硬编码的延迟：

| 技能 | 最小识别时间 |
| --- | --- |
| 简单 | 1.00 秒 |
| 普通 | 0.50 秒 |
| 困难 | 0.30 秒 |
| 专家 | 0.20 秒 |

这就是"简单机器人感觉很笨"效果的大部分来源----简单机器人一旦注意到你，瞄准并不差，只是需要五倍的时间才能注意到你的存在。

### 瞄准：跟踪频率

机器人不会连续跟踪你。它们以一个固定间隔采样你的位置和速度，并从中预测一条直线：

| 技能 | 重新计算间隔 | 等效频率 |
| --- | --- | --- |
| 简单 | 1.00 秒 | 1 次/秒 |
| 普通 | 0.25 秒 | 4 次/秒 |
| 困难 | 0.10 秒 | 10 次/秒 |
| 专家 | 0.05 秒 | 20 次/秒 |

**例外：** 间谍机器人被硬编码为使用普通跟踪频率，无论其实际技能等级如何----专家间谍仍然像普通机器人一样瞄准。还有一个公开演示视频，并排比较了跟踪频率，如果你想看到 1 倍与 20 倍差距的动态效果。

### 瞄准：武器专属技能

机器人不只是指向你的身体中心----它们有每把武器的逻辑，有些逻辑真的有问题：

**榴弹发射器和粘性发射器。** 所有技能等级都会补偿垂直弹道，使用来自 `tf_bot_ballistic_elevation_rate` cvar 的固定值。因为这种补偿只对基础武器 ID 生效，所以较快的射弹变体（Loch-n-Load，任何带有射弹速度修改器的武器）不会得到正确调整的弹道。而且由于它是按特定武器 ID 触发的，Loose Cannon----一个完全不同的 ID----根本得不到弹道补偿。

**猎人弓。** 简单机器人不补偿箭矢下坠，也从不瞄准头部。普通技能机器人会补偿弹道，但只在 150 HU 范围内瞄准头部。困难/专家机器人总是瞄准头部。

**火箭发射器。** 超过 150 HU，非简单机器人会瞄准你的脚而不是身体中心，以最大化溅射伤害和击退几率。在 150 HU 以内，它们切换为瞄准头部。简单机器人总是瞄准身体中心，无论距离如何。这也受武器 ID 锁定：Direct Hit 和 Cow Mangler 不继承这个行为。对 Direct Hit 来说合理（没有 AoE 可利用）；对 Cow Mangler 来说完全没有意义----这部分 AI 在该武器存在之前就已编写，之后从未被重新审视过。

**狙击步枪。** 简单瞄身体。普通大约从身体到头部的三分之一处瞄准。困难/专家直接瞄准头部。这在 MvM 中不那么重要，因为机器人的爆头无论如何都不获得伤害加成。

### 听觉：对隐秘射击的敏感性

每次枪声都会将射手的位置提示给附近机器人，即使穿墙，范围可达 3000 HU，100% 几率注意到（`tf_bot_notice_gunfire_range`）。但有一部分武器被标记为"隐秘"----仅在 500 HU 内可闻（`tf_bot_notice_quiet_gunfire_range`），即使在这个范围内，也有一个随技能变化的几率：

| 技能 | 注意到隐秘射击的几率 |
| --- | --- |
| 简单 | 10% |
| 普通 | 30% |
| 困难 | 60% |
| 专家 | 90% |

如果过去 3 秒内听到过*响亮*的射击声，该概率减半----响亮的声音掩盖了安静的声音。

隐秘武器 ID 列表自 2010 年 12 月以来就没有更新过。此后添加的任何使用全新武器 ID 的武器默认都被视为响亮，无论逻辑上它有多安静----除非它恰好重用了旧的 ID。具体来说：

| 武器 ID | 涵盖范围 |
| --- | --- |
| `TF_WEAPON_KNIFE` | 所有间谍匕首 |
| `TF_WEAPON_FISTS` | 机枪手专属拳击（他的多职业拳击实际上是 `TF_WEAPON_FIREAXE`） |
| `TF_WEAPON_PDA` | 认为未直接使用 |
| `TF_WEAPON_PDA_ENGINEER_BUILD` | 工程师的建筑 PDA |
| `TF_WEAPON_PDA_ENGINEER_DESTROY` | 工程师的拆除 PDA |
| `TF_WEAPON_PDA_SPY` | 间谍的伪装工具 |
| `TF_WEAPON_BUILDER` | 间谍的工程师/破坏工具包 |
| `TF_WEAPON_MEDIGUN` | 所有医疗枪 |
| `TF_WEAPON_DISPENSER` | 可能未使用（补给器是物体，不是武器） |
| `TF_WEAPON_INVIS` | 所有间谍隐形手表 |
| `TF_WEAPON_FLAREGUN` | 所有火焰兵信号枪，*除了* Manmelter |
| `TF_WEAPON_LUNCHBOX` | 三明治、Dalokohs 棒、Buffalo 牛排三明治、Bonk！、Crit-a-Cola |
| `TF_WEAPON_JAR` | Jarate（不是 Mad Milk----单独的、非隐秘 ID） |
| `TF_WEAPON_COMPOUND_BOW` | 猎人弓 |
| `TF_WEAPON_SWORD` | Eyelander、Skullcutter、Claidheamh Mòr、Persian Persuader、Half-Zatoichi |
| `TF_WEAPON_CROSSBOW` | Crusader's Crossbow |

列表腐烂的经典例子：Manmelter 有自己的 ID（`TF_WEAPON_RAYGUN_REVENGE`），是在隐秘列表冻结后添加的----所以它被视为响亮，尽管实际上它是一把信号枪。Scorch Shot 发布得更晚，但重用了基础的 `TF_WEAPON_FLAREGUN` ID，因此仍然被视为隐秘。不合逻辑，但代码就是如此。

### 策略：威胁优先级

当多个敌人同时可见时，机器人会权衡距离、是否正在被攻击，以及----简单难度以上----主要威胁是否正在被治疗：

| 技能 | 转而攻击治疗者？ |
| --- | --- |
| 简单 | 否 |
| 普通 | 50% 几率 |
| 困难 | 是 |
| 专家 | 是 |

500 HU 以外的敌人通常被降级为非紧迫威胁。例外：困难/专家机器人始终将远处的医疗兵和工程师视为紧迫威胁，并且任何大致朝你方向瞄准的敌方狙击手始终被视为紧迫威胁，无论距离和技能等级如何。

| 技能 | 远处的医疗兵/工程师/正在瞄准的狙击手 = 紧迫威胁？ |
| --- | --- |
| 简单/普通 | 否 |
| 困难/专家 | 是 |

那个狙击手检查有一段有趣的历史。Sigsegv 最初的文档假设游戏要求狙击手的瞄准向量与机器人的相对位置之间的点积*恰好为零*----这个比较精度太高，以至于在浮点数运算中几乎永远不会触发，使整个特性成为死代码。后来发布的更正（归功于更干净的 Hex-Rays 反编译）显示实际检查是 `点积 > 0`：任何正对着你到你垂直方向之间的狙击手都算作紧迫威胁；从垂直到你背对方向则不算。最初的误读来自于对 SSE 浮点比较的不良反编译----逆向工程一个 AAA 级游戏的二进制文件并非精确科学。

### 移动：躲避

简单机器人从不躲避，到此为止。普通及以上机器人在持有战斗武器、过去 3 秒内看到过敌人且该敌人对它们有视线时，会左右躲避（33% 向左、33% 向右、33% 不做任何事，根据检测到的空隙加权）。

如果以下任一条件适用，它们将*不会*躲避：设置了 `DisableDodge` 属性、当前行为要求加速、当前无敌（任何类型的 über）、正在嘲讽/挑衅、正在玩工程师、隐形或被伪装成间谍、作为狙击手开镜或作为机枪手预热转轮、或正在拉弓准备猎人弓。

### 移动：避免推挤敌人

普通以上难度，机器人会特意避免在移动时撞到敌人：

| 技能 | 避免撞到敌人？ |
| --- | --- |
| 简单 | 否 |
| 普通 | 否 |
| 困难 | 是 |
| 专家 | 是 |

实际上这主要对间谍机器人重要----避免与敌方玩家尴尬碰撞正是会暴露伪装的那种事。

### 火焰兵：压缩爆精通

压缩爆有两个用途：反射射弹（PvP 和 MvM）以及将附近敌人推下悬崖（仅 PvP）。机器人是否会在有效机会时开火是一个基于技能的概率判断：

| 技能 | 压缩爆触发几率 |
| --- | --- |
| 简单 | 0% |
| 普通 | 50% |
| 困难 | 90% |
| 专家 | 100% |

简单火焰兵机器人字面上无法使用压缩爆----这个判定被硬编码为永远不会成功，不仅仅是很"罕见"。

### 间谍：伪装有效性

两个独立的轴随技能变化。伪装的*选择*：

| 技能 | 伪装方法 |
| --- | --- |
| 简单/普通 | 随机职业，忽略敌方队伍实际正在玩的职业 |
| 困难/专家 | 选择一个真实的敌方玩家并复制其确切职业 |

伪装的*表演*：

| 技能 | 伪装/隐身时的行为 |
| --- | --- |
| 简单/普通 | 看到敌方玩家时会盯着他们看（可疑） |
| 困难/专家 | 故意避免眼神接触（更令人信服） |

### 间谍：背刺攻击倾向

在远距离（最高 300 HU，`tf_bot_spy_knife_range`），间谍机器人只会在能看到受害者并且受害者的背部至少部分朝向它时才会尝试背刺。技能决定了这个背部角度允许偏离中心的程度：

| 技能 | 角度容差 |
| --- | --- |
| 简单 | 即使正对着它也会尝试 |
| 普通 | 离你背部 ±45° |
| 困难 | 离你背部 ±78° |
| 专家 | 离你背部 ±90°（完整后方 180° 弧） |

简单间谍机器人实际上是自杀式的----它们会尝试刺杀一个正盯着它们看的人。**例外：** 在 Mann vs. Machine 模式中，每个间谍机器人无论实际技能如何都被强制使用普通角度限制。

### 战术：武器选择

仅在简单以上触发，在 MvM 中基本无关紧要，因为那里的机器人通常有严格的武器限制：

- **侦察兵**：主武器弹匣为空时切换到副武器。
- **士兵**：弹匣为空*且*目标在 500 HU 以内时切换到副武器。
- **狙击手**：目标在 750 HU 以内时切换到副武器。
- **火焰兵**：目标在 750 HU 以外时切换到副武器，除非目标是士兵或爆破手。

### 战术：掩护换弹

不在 MvM 中使用。如果机器人的当前行为没有指示它撤退、主武器弹匣为空且没有被 über 充能，较高技能的机器人会暂时退到掩护下换弹，而不是对着你空击：

| 技能 | 撤退换弹？ |
| --- | --- |
| 简单 | 否 |
| 普通 | 否 |
| 困难 | 是 |
| 专家 | 是 |

### 控制点模式：防守者巡逻

不在 MvM 中使用。在防守控制点时，较高技能的机器人更可能离开控制点去猎杀敌人（"搜索并摧毁"），但只有在 `tf_bot_defense_must_defend_time` 还剩足够多时间时才如此：

| 技能 | 巡逻几率 |
| --- | --- |
| 简单 | 10% |
| 普通 | 50% |
| 困难 | 75% |
| 专家 | 90% |

### 控制点模式：阻挡占领

不在 MvM 中使用。防守机器人争夺敌方占领尝试时的行为：

| 技能 | 会尝试阻挡占领吗？ |
| --- | --- |
| 简单 | 否 |
| 普通 | 50% 几率 |
| 困难 | 是 |
| 专家 | 是 |

## 结论

![瞄准转轮机枪的 TF2 机枪手机器人](assets/tf2-bot-ai-heavy-aim.png)

这些都不是 Valve 的猜测错误----这是一个故意的、完全确定性的评分和概率系统，只是从未在任何官方文档中写下来。有几件事值得记住：

1. **"技能"是一组独立的调节旋钮**，而非一个全局乘数。反应时间、瞄准频率和每个战术行为都独立地按比例变化，其中一些（间谍跟踪频率、MvM 背刺角度）会无论技能如何都被硬编码覆盖。
2. **有些问题是真的有 Bug，而不仅仅是老旧。** 自 2010 年以来冻结的隐秘武器列表、Cow Mangler 毫无理由地缺少瞄脚逻辑、花了多年才被正确反编译的狙击手点积检查----Valve 的 AI 代码和其他任何一个 17 年历史的代码库一样有伤痕。
3. **你可以利用所有这些。** 知道狙击手机器人在普通难度不会爆你的头、简单火焰兵机器人字面上无法把你的火箭反射回来、简单间谍机器人会尝试当面刺杀你。这不是运气。这是一份规格说明书。

非常感谢 sigsegv 最初的代码挖掘工作，这些工作使得本文的大部分内容成为可能；感谢 TF2 Wiki 提供的关于机器人命令和地图支持的基准文档；以及感谢社区中每一位仍然在探究这个 17 年历史的机器人 AI、试图弄清楚它为什么做它所做的那些事情的成员。
