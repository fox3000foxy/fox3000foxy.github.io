# 我的热爱

我一直想写这个博客，但总是犹豫不决 :/

可能是因为我想分享生活，但不想透露个人信息？大概就是这个原因吧。

## 编程

我的爱好很多：我热爱编程，从博客的其他内容你大概也看出来了。从零开始构建东西、解决问题、看着自己的作品活起来----那种满足感无与伦比。无论是一个小 CLI 工具还是一个完整的 Web 应用，这个过程永远不会腻。

我对**开源**有着特别的热爱----分享就是关爱，我真心希望有人会觉得我的代码有用。我的大部分项目都在[我的 GitHub](https://github.com/fox3000foxy)上，你也可以在[项目页面](/projects)浏览它们。

## 自动化一切

我还热衷于自动化。用 GitHub Actions 和工作流是我最爽的体验之一。只要能把手动流程替换成脚本或流水线，我二话不说就干。

我最近也开始用 SSH 密钥签署提交，为此写了一个脚本，你可以在[这个 Gist](https://gist.github.com/fox3000foxy/95500d129cd4bf5c173c323d2492569a) 里找到。

我喜欢发现像 UTAU 这样的老技术----我觉得这个概念很迷人。了解前 AI 和云计算时代的人们是如何构建东西的，有种特别的感觉。

我的主要爱好是边听音乐边编程。没有什么比配上合适的歌单进入心流状态更棒的了。我最近也挺喜欢散步的，不知道为啥 😕。

## 找替代方案

我也喜欢找替代方案来避免付费----或者说，跳出固有思维。比如 [Nibi](https://github.com/Let-s-Learn-Japanese-Together/Nibi) 就是我最近的创作之一，我在命令处理、数据库管理和守护进程方面找到了免费的替代方案。这不是抠门----这是挑战！
