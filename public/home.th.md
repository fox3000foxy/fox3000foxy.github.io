## เกี่ยวกับฉัน

ฉันชื่อ Fox ฉันไม่ได้กำหนดคำนำที่ถูกต้องของตัวเอง เพราะฉันยังไม่พบตัวเอง และฉันเป็นนักซอฟต์แวร์ที่ชอบทำงานด้วย TypeScript, Node.js และ React และค้นหาความรู้ใหม่ๆ ทุกครั้ง โครงการส่วนใหญ่ของฉันอยู่บน GitHub ภายใต้บัญชี fox3000foxy

ฉันเป็นคนรักแนวคิดของโอเพนซอร์ส เพราะฉันรักการแบ่งปันสิ่งๆ นั้น ฉันยังชอบค้นหาความรู้เกี่ยวกับเทคโนโลยีเก่าๆ เช่น UTAU ฉันพบแนวคิดนั้นเป็นเรื่องที่น่าสนใจ ฉันยังชอบ Vtubers เช่นกัน และฉันอยากจะเป็น Vtuber แต่ฉันไม่กล้า

ฉันยังชอบค้นหาวิธีแก้ปัญหาในการไม่ต้องจ่ายเงินหรือไม่ต้องจ่ายเงินถ้าไม่คิดนอกกรอบ เช่น ในการสร้าง Nibi ฉันค้นหาวิธีแก้ปัญหาการจัดการคำสั่ง การจัดการฐานข้อมูล และ daemon ฉันยังชอบเล่นกับ GitHub Actions และ workflows เป็นหนึ่งในสิ่งที่ทำให้ฉันรู้สึกดีที่สุด ฉันยังเริ่มลงชื่อใน commit ด้วย SSH Key และคุณสามารถหาสคริปต์ที่ฉันทำไว้ได้บน gist นั้น

## ภาษาและเทคโนโลยี

ฉันหลักๆ ใช้ภาษา TypeScript และ React แต่ในอดีต ฉันเคยใช้ HTML, CSS และ JavaScript ในการสร้าง launcher ฉันรู้สึกว่ามันค่อนข้างน่าประหลาดใจ แต่ฉันไม่ได้บอกว่ามันค่อนข้างน่าประหลาดใจจริงๆ ฉันยังรู้ภาษา Python, C# แต่ฉันไม่ชอบมัน Java แต่ฉันไม่เคยใช้มันมากนัก ตอนนี้ฉันใช้มันในการสร้าง plugin สำหรับเกม Minecraft ของ Eminium Games ฉันยังรู้ภาษา C++ แต่ฉันไม่เคยใช้มันจริงๆ ฉันยังเรียนรู้ภาษา C ด้วย project bareiron นั้น และอื่นๆ ฉันยังไม่รู้ภาษา Rust หรือ Go แต่ฉันอยากจะเรียนรู้

ฉันยังมีความรู้ในด้านการวาดภาพ การผลิตเพลง และการแก้ไขวิดีโอ -- แต่ฉันไม่ค่อยดีในเรื่องเหล่านี้ ฉันแค่ทำเพื่อความสนุก

ฉันยังใช้ framework และ library เช่น Node.js, Express.js, React, Discord.js และอื่นๆ ฉันยังใช้เครื่องมือ เช่น Git, Docker และ Linux distributions เช่น Debian, Arch Linux และ Ubuntu ฉันยังมีความรู้ในด้าน database เช่น MongoDB และ MySQL

สำหรับเครื่องมือ ฉันยังใช้ Visual Studio Code เป็นเครื่องมือหลักในการเขียนโปรแกรม ฉันยังใช้เครื่องมืออื่นๆ เช่น Postman สำหรับการทดสอบ API และเครื่องมืออื่นๆ สำหรับงานเฉพาะ

ฉันยังมีความรู้ในหลักการของ JavaScript เพราะฉันใช้ JavaScript มาตั้งแต่ฉันอายุ 8 ปี ฉันไม่คิดว่ามันค่อนข้างน่าประหลาดใจ แต่ฉันรู้ว่ามีคนอื่นๆ ที่ดีกว่าฉันในด้านการเขียนโปรแกรมและชื่อเสียงที่ไม่ดี และมีคนอื่นๆ ที่ได้รับค่าจ้างมากกว่าฉัน แต่ไม่คิดว่ามันค่อนข้างน่าประหลาดใจจริงๆ

## งานอดิเรก

ฉันมีงานอดิเรกมากมาย แต่งานอดิเรกหลักของฉันคือการเขียนโปรแกรมในขณะที่ฟังเพลง ฉันยังชอบการวาดภาพและ ฉันยังชอบการ walking

## ความหลงใหล

ฉันเคยเขียนบล็อกเกี่ยวกับความหลงใหลของฉันในบล็อกนี้ คุณสามารถอ่านได้: ความหลงใหลของฉัน

## แพ็คเกจ

ฉันยังเขียนแพ็คเกจ npm เช่น fetch-tor-proxy หรือ fake-data-npm แต่ไม่มีใครใช้พวกมันเลย รวมถึงฉันเอง แต่ฉันหวังว่าพวกมันจะทำงานได้จริงๆ!

## โครงการ

ฉันมีโครงการมากมาย ตอนนี้ฉันมีโครงการ 146 โครงการ แต่โครงการ 103 โครงการนั้นเปิดเผยต่อสาธารณะ ฉันจะแสดงโครงการเหล่านั้นในบล็อกของฉันในอนาคต

อัปเดต: ฉันมีโครงการ 158 โครงการ ตอนนี้ ฉันจะแสดงโครงการเหล่านั้นในบล็อกของฉันในอนาคต

หมายเหตุ: ฉันมีโครงการส่วนตัวจำนวนมาก และฉันไม่ต้องการพูดเกี่ยวกับโครงการเหล่านั้น แต่โครงการเหล่านั้นเป็นโครงการที่ฉันไม่ต้องการแบ่งปันหรือโครงการที่ยังไม่เสร็จสิ้น หรือโครงการที่ไม่ค่อยมีประโยชน์ต่อผู้อื่น

คุณสามารถค้นหาการทำงานของฉันได้บนหน้า Project และบนบัญชี GitHub ของฉัน

## ฉันทำงานให้กับ

ฉันเคยทำงานให้กับหลายๆ คน ฉันเป็นเพื่อนกับคนงานของ Discord และฉันรู้คนสร้างสรรค์บางคน เช่น NTTS, Squiduu, HatsuOtaku, Sciences Trash, Sushi Nihiliste หรือแม้กระทั่งผู้เล่าเรื่องชาวฝรั่งเศส Ego ฉันเคยโดนบล็อกโดย What a Fail เพราะฉันพูดคำว่า Hello ฉันรู้ Belle Delphine และ ggu.bbu2 ที่ฉันเคารพ และอื่นๆ!

ฉันไม่ต้องการรู้คนดังในโทรทัศน์ เพราะฉันคิดว่าพวกเขาไม่ใช่คนธรรมดา และมีคนดังที่มีความเห็นอกเห็นใจน้อยมาก ฉันเชื่อว่ามีคนดังที่ดี แต่คนดังในโทรทัศน์เป็นส่วนใหญ่ไม่ค่อยเห็นอกเห็นใจ

ฉันยังชอบการทำให้ระบบทำงานโดยอัตโนมัติ และฉันเคยแสดงตัวในคลิปวิดีโอของคนสร้างสรรค์บางคน ไม่เชิงกอด แต่หมายความว่าฉันสามารถสร้างชื่อเสียงให้ตัวเองได้

## คำสุดท้าย

ในบล็อกนี้ ฉันจะแบ่งปันความคิดและความคิดเห็นของฉัน และฉันจะแบ่งปันความคิดเห็นของฉันเกี่ยวกับโครงการและความคิดเห็นของฉันเกี่ยวกับงานอดิเรกของฉัน คุณจะรู้ว่าฉันคิดอย่างไร

อย่างไรก็ตาม บัญชี GitHub ของฉันจะแสดงโครงการและความคิดเห็นของฉันในเรื่องนั้นในเวลาจริง คุณจะรู้ว่าฉันคิดอย่างไรในเรื่องนั้น

หมายเหตุ: ฉันชอบยุคของโครงการของฉัน ฉันชอบเห็นปีเก่าๆ เกิดขึ้นบนบัญชี GitHub ของฉัน ฉันไม่คิดว่ามันค่อนข้างน่าประหลาดใจ

หมายเหตุ: ฉันกำลังเขียนบล็อกและฉันเพิ่มลิงก์โปรไฟล์หลักของฉันในบล็อกนี้อีกครั้ง
