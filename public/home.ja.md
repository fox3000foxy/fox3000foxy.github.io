## 自己紹介

フォックスです。代名詞はまだ決めてないんだ。まだ自分探し中だからね。ソフトウェアエンジニアをやっていて、TypeScript、Node.js、React で作業するのと、新しい技術を発見するのが大好き。プロジェクトのほとんどはオープンソースで、GitHub の `fox3000foxy` アカウントで公開してる。

オープンソースのコンセプトがもう大好きで大好きで仕方ないんだ。だって人と共有するのが好きだからね。UTAU みたいな古い技術を発見するのも好きで、そのコンセプトにすごく魅了されてる。Vtuber も大好きで、自分もなりたいけど、残念ながらシャイなんだ。

あと、有料のものや、既成概念にとらわれない考え方をしないとお金を払わなきゃいけないものに対して、回避策を見つけるのも大好き。例えば [Nibi](https://github.com/Let-s-Learn-Japanese-Together/Nibi) は、コマンド管理、データベース管理、デーモンに対して無料の回避策を見つけた最新の作品のひとつ。それに GitHub Actions とワークフローで遊ぶのは最高の気分だよ。SSH キーでコミットに署名し始めて、そのスクリプトは [この gist](https://gist.github.com/fox3000foxy/95500d129cd4bf5c173c323d2492569a) で公開してる。

## 言語とテクノロジー

今は主に TypeScript と React でコードを書いてるけど、昔は生の HTML、CSS、JavaScript でランチャーを書いてた。Python、C#（大嫌い）、Java（たまに [Eminium Games](https://github.com/Eminium-Games/) の Minecraft プラグインを書くのに使う）もできる。C++ も少しできるけど、今はもう書き方を忘れちゃった。そして [bareiron](https://github.com/p2r3/bareiron) プロジェクトで C を勉強中。そんな感じで、今は Rust も Go もできないけど、いつか覚えたい。

絵を描くのも少しできるけど、上手じゃないよ。ただの趣味。音楽制作もちょっとやるけど、それも上手じゃない。ただの趣味。動画編集も少しできるけど、それも上手じゃない。

使ってるフレームワークやライブラリは Node.js、Express.js、React、Discord.js など。ツールは Git、Docker、Debian、Arch Linux、Ubuntu などの Linux ディストリビューションを使ってる。データベースは MongoDB と MySQL の知識がある。

ツール類は、メインのコードエディタとして Visual Studio Code、API テスト用に Postman などを使ってる。

JavaScript の原理はかなり理解してる。だって8歳の頃から JavaScript でコードを書いてるからね。😄 自慢したいわけじゃないよ。もっと悪い状況で僕よりすごい開発者もいれば、完全な詐欺師なのに僕より稼いでる人もいるってわかってるから。

たまに npm パッケージを書いてる。[fetch-tor-proxy](https://www.npmjs.com/package/fetch-tor-proxy) とか [fake-data-npm](https://www.npmjs.com/package/fake-data-npm) とか。誰にも使われてないし、僕自身も使ってないけど、いつか爆発的に流行ってほしい！

## プロジェクト

プロジェクトがめちゃくちゃ多いんだ。今は全部で158のリポジトリがあって、そのうち108が公開！ おそらくブログセクションで紹介すると思う。

注：プライベートリポジトリもたくさんあって、それについては話したくない。でも、主に世界と共有したくないプロジェクトとか、まだ完成してないやつとか、ただの趣味で僕以外には全然役に立たないものだよ。

プロジェクトは[プロジェクトページ](https://fox3000foxy.github.io/projects)と[GitHub プロフィール](https://github.com/fox3000foxy)で見られるよ。

## 仕事の関係

いろんな人のために仕事をしてきたよ！ Discord の社員と友達だし、NTTS、Squiduu、HatsuOtaku、Sciences Trash、Sushi Nihiliste、それにフランスの語り手 Ego とかのクリエイターと知り合い。What a Fail には「こんにちは」って言っただけでブロックされたよ。Belle Delphine や ggu.bbu2（よろしく！）とかも知ってる！

でもテレビスターとは知り合いたくないな。手が届かない存在で、気取ってると思うから。いい人もたくさんいると思うけど、ショービジネスの有名人は大抵わがままだよ…

自動化に情熱を持っているし、有名クリエイターの動画に出たこともある。自慢じゃないけど、小さなニッチを築けたってことだと思う。

## おわりに

このブログでは、進捗や考え、共有したいことを何でも発信していくよ。そうすればみんなが僕の考え方をわかってくれる。要するに、GitHub は全プロジェクトとそのリアルタイムの進捗をリストアップする場所になる。プロジェクトの年齢が大好きなんだ。自分のリポジトリの日付が古くなっていくのを見るのが好きでね。だからプロフィールのコミット日付が改ざんされてても不思議じゃない！ 😁

そんなわけで、ブログを書き始めたよ。メインのリンクを別のセクションにまとめた。
