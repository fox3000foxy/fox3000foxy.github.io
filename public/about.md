# About

Hey, I'm **Fox3000foxy**.

I write about code, games, reverse-engineering, automation, and open-source. This blog is where I document things I've built, broken, or figured out.

## What you'll find here

- Technical deep-dives (Minecraft pathfinding, serverless bots, UTAU synthesis)
- Automation hacks (GitHub Actions as a VPS, git as a database)
- Reverse-engineering (how things work under the hood)
- Random projects I'm proud of

## How this blog works

Built with React + TypeScript + Vite. All articles are written in Markdown with YAML frontmatter, translated by hand into 10 languages. No CMS, no database -- just static files deployed on GitHub Pages via CI.
