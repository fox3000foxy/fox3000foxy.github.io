Working on a New Project

A look at the process of starting and developing a new website.

metawebdev
𝕏in

The Project

The project I'm working on is called LLJT:

It's a website that's also a PWA, so you can use it like a mobile app. It uses MaterialUI to behave like a real phone app. I spent a while on the Mui imports: I went from 11707 modules down to 595 in the end, by importing each icon line by line instead of the destructured import. That's when I learned that the destructured import loads the whole icon library, while individual imports only load the ones you actually use.

Nibi is the bot connected to this website.Grading relies on Google Forms: We use multiple-choice quizzes to evaluate our students, and we also hand out Discord roles, plus emojis and channels, to our students when they pass an important exam.

The goal of this project is to help people learn Japanese together with us, since it's something I want to do myself too. Students will also unlock partnerships with Crunchyroll and other platforms, to reward their progress.

Nibi and the website are hosted by Cloudflare Workers (Interaction URL with Hono Server) and GitHub Pages with React, respectively. The website's code is not open source, but Nibi's is, and you can find it on this GitHub repo. The website stays private because it contains private information, but if you want to know how I built it, ask me on Discord and I'll gladly walk you through the process! It uses a GitHub Action I created to avoid paying for GitHub Enterprise, plus several other tools and techniques I can tell you about if you're interested!

For the past few days, I've been having a lot of fun finding workarounds to host my projects without paying for hosting. That's why I made Nibi an Interaction Endpoint bot, to host it for free on Cloudflare Workers, and why I created a GitHub Action to deploy the website for free on GitHub Pages. Hunting for these workarounds is still one of the most exciting parts of coding for me: you have to think differently and build creative solutions, and it's exactly that no-budget challenge that motivates me!

Using GitHub Actions outside their intended purpose, and using Cloudflare Workers to "host" a bot, is also a way to learn new things and discover new technologies, like cloud hosting. I don't want to pay for hosting anymore.

I'm still working on it but you can join the Discord server if you want to follow along and see how it evolves, and maybe even join the project if you're interested! The server is open to everyone, and we'd love to have more people learning Japanese together! You'll find the invite link on the website, or you can ask me for it directly!

这个项目

我正在做的项目叫 LLJT：

这是一个网站，同时也是 PWA，可以像手机应用一样使用。它用 MaterialUI 来表现得像真正的手机应用。 我在 Mui 的导入上花了不少时间：从 11707 个模块一路砍到最后的 595 个，方法是逐行单独导入每个图标，而不是用解构导入。就在那时我学到，解构导入会把整个图标库都加载进来，而单独导入只加载用到的图标。

Nibi 是连接到这个网站的机器人。评分机制基于 Google Forms： 我们用选择题来考核学生，学生在通过重要考试后还会获得 Discord 身份组、表情和频道。

这个项目的目标是帮助大家和我们一起学日语，这也是我自己想做的事。 学生还会解锁与 Crunchyroll 等平台的合作奖励，用来嘉奖他们的进步。

Nibi 和网站分别托管在 Cloudflare Workers（带 Hono Server 的 Interaction URL）和 GitHub Pages（React）上。 网站代码不开源，但 Nibi 开源，你可以在这个仓库找到它。网站因为包含隐私信息所以保持私有，但如果你想知道我是怎么搭建的，可以在 Discord 上问我，我很乐意一步步讲给你听！它用到了我写的一个 GitHub Action（为了避开 GitHub Enterprise 的付费），以及其他一些我可以给你介绍的工具和技巧！

这几天我特别享受为项目寻找免费托管的变通方案。正因如此，我把 Nibi 做成了 Interaction Endpoint 机器人，免费跑在 Cloudflare Workers 上，还写了一个 GitHub Action 把网站免费部署到 GitHub Pages。对我来说，寻找这类变通方案始终是写代码最刺激的部分：要换个思路，构造有创意的解法，而正是这种零预算的挑战激励着我！

把 GitHub Actions 用在原本设计之外的用途，用 Cloudflare Workers 来"托管"机器人，也是学习新东西、发现云托管这类新技术的方式。我不想再为托管付费了。

我还在继续做这个项目，如果你想关注进展、看看它怎么演变，甚至加入进来，可以加入 Discord 服务器！服务器对所有人开放，我们很希望有更多人一起来学日语！邀请链接在网站上有，也可以直接问我要！

新プロジェクトに取り組む

March 13, 2026·1 min read

Fox3000foxyVerified@fox3000foxy

新ウェブサイトの立ち上げと開発過程の概要。

metawebdev
𝕏in

プロジェクト

取り組んでるプロジェクトはLLJTって言う。

ウェブサイトでPWAでもある。だからモバイルアプリとして使える。本物の電話アプリみたいに振る舞うためMaterialUIを使ってる。 Muiのimportには時間かけた。11707モジュールから最後595まで落とした。各アイコンを分解 import じゃなく1行ずつ import してね。そのとき分解 import はアイコンライブラリ全体を読み込むのに、個別 import は使うものだけ読むって学んだ。

Nibiはこのサイトに繋がるボットだ。採点はGoogle Forms頼みだ。 学生評価に選択問題を使って、大事な試験に受かった学生にDiscord役職や絵文字やチャンネルも付ける。

このプロジェクトの目標は、私自身もやりたいことだから、私達と一緒に日本語を学ぶ人を助けることだ。 学生は進行のご褒美にCrunchyrollや他プラットフォームとの提携も解除する。

NibiとサイトはそれぞれCloudflare Workers（Hono Server付きInteraction URL）とReact付きGitHub Pagesでホストしてる。 サイトコードはオープンソースじゃないけど、Nibiはそうだ。このGitHubリポジトリにある。サイトは個人情報入りだから非公開のままだ。でもどう作ったか知りたければDiscordで聞いて。過程を喜んで説明するよ！GitHub Enterprise払い避けに作ったGitHub Actionや、興味あれば説明できる他道具や技術も使ってる！

数日前から、ホスティング払わずプロジェクトをホストする回避策探しを大いに楽しんでる。だからNibiをInteraction EndpointボットにしてCloudflare Workersで無料ホストして、GitHub Pagesに無料デプロイするGitHub Actionを作った。この回避策探しは今も私のコードでいちばん刺激的な部分だ。違う考え方をして創造的な解を作らなきゃいけない。まさに予算なしのこの挑戦が私を動かす！

本来用途外でGitHub Actionsを使うこと、ボット「ホスティング」にCloudflare Workersを使うことも、新しいこと学んでクラウドホスティングみたいな新技術を発見する方法だ。ホスティングにお金払いたくない。

まだ取り組み中だけど、進捗追ってどう変わるか見たければDiscordサーバーに参加できる。興味あればプロジェクト参加もできるかも！サーバーは誰でも開いてて、一緒に日本語学ぶ人がもっとほしい！招待リンクはサイトにある。直接聞いてもいいよ！

새 프로젝트 작업 중

March 13, 2026·3 min read

Fox3000foxyVerified@fox3000foxy

새로운 웹사이트를 시작하고 개발하는 과정에 대한 미리보기.

metawebdev
𝕏in

프로젝트

제가 작업하고 있는 프로젝트의 이름은 LLJT예요.

이 프로젝트는 PWA이기도 한 웹사이트라서 모바일 앱처럼 사용할 수 있어요. 진짜 휴대폰 앱처럼 동작하도록 MaterialUI를 사용해요. Mui import 때문에 한동안 애를 먹었어요. 구조 분해 import 대신 각 아이콘을 한 줄씩 따로 import해서 결국 11707개 모듈에서 595개로 줄였어요. 그때 구조 분해 import는 아이콘 라이브러리 전체를 불러오지만, 개별 import는 실제로 사용하는 것만 불러온다는 걸 알게 되었어요.

Nibi는 이 웹사이트에 연결된 봇이에요.평가는 Google Forms를 기반으로 해요. 저희는 퀴즈로 학생들을 평가하고, 중요한 시험에 합격한 학생들에게 Discord 역할과 이모지, 채널도 부여해요.

이 프로젝트의 목표는 사람들이 저희와 함께 일본어를 배우도록 돕는 거예요. 저 자신도 하고 싶은 일이기도 하고요. 학생들은 실력이 늘면 Crunchyroll과 다른 플랫폼과의 제휴 혜택도 받을 수 있어서, 학습의 보상이 될 거예요.

Nibi와 웹사이트는 각각 Cloudflare Workers(Interaction URL과 Hono 서버)와 React를 올린 GitHub Pages에서 호스팅돼요. 웹사이트 코드는 오픈 소스가 아니지만 Nibi는 오픈 소스라서 이 GitHub 저장소에서 찾으실 수 있어요. 사이트에는 비공개 정보가 들어 있어서 계속 비공개로 두지만, 어떻게 만들었는지 궁금하시면 Discord로 물어봐 주세요. 과정을 기꺼이 설명해 드릴게요! GitHub Enterprise 비용을 내지 않으려고 제가 만든 GitHub Action을 비롯해, 관심 있으시면 설명해 드릴 수 있는 도구와 기법들을 여러 가지 사용했어요!

요즘은 호스팅 비용을 내지 않고 제 프로젝트들을 호스팅할 우회 방법을 찾는 재미에 푹 빠져 있어요. 그래서 Nibi를 Interaction Endpoint 봇으로 만들어 Cloudflare Workers에 무료로 호스팅하고, GitHub Pages에 사이트를 무료로 배포하는 GitHub Action을 만든 거예요. 이런 우회 방법을 찾는 일은 저에게 여전히 코딩에서 가장 신나는 부분 중 하나예요. 다르게 생각하고 창의적인 해결책을 만들어야 하니까요. 바로 그 무예산 도전이 저를 움직이는 원동력이에요!

본래 용도에서 벗어나 GitHub Actions를 사용하고, Cloudflare Workers로 봇을 "호스팅"하는 것은 새로운 것을 배우고 클라우드 호스팅 같은 새로운 기술을 발견하는 방법이기도 해요. 저는 이제 호스팅에 돈을 내고 싶지 않아요.

아직 작업 중이지만, 진행 상황을 지켜보고 어떻게 발전하는지 보고 싶으시면 Discord 서버에 참여해 보세요. 관심 있으시면 프로젝트에 합류하실 수도 있어요! 서버는 모두에게 열려 있고, 함께 일본어를 배우는 분들이 더 많아졌으면 해요! 초대 링크는 사이트에서 찾으실 수 있고, 저에게 직접 물어보셔도 돼요!

Proje

Üzerinde çalıştığım projenin adı LLJT:

Bu aynı zamanda bir PWA olan bir web sitesi, yani mobil uygulama gibi kullanılabiliyor. Gerçek bir telefon uygulaması gibi davranması için MaterialUI kullanıyor. Mui importlarıyla bir süre uğraştım: yıkıcı import yerine her ikonu satır satır import ederek 11707 modülden sonunda 595 modüle indim. O zaman yıkıcı importun tüm ikon kütüphanesini yüklediğini, bireysel importların ise sadece kullanılanları yüklediğini öğrendim.

Nibi bu web sitesine bağlı bot.Notlandırma Google Forms üzerinden yapılıyor: Öğrencilerimizi testlerle değerlendiriyoruz ve önemli bir sınavı geçtiklerinde onlara Discord rolleri, emojiler ve kanallar da veriyoruz.

Bu projenin amacı insanların bizimle birlikte Japonca öğrenmesine yardım etmek, çünkü bu benim de kendim yapmak istediğim bir şey. Öğrenciler ilerlemelerini ödüllendirmek için Crunchyroll ve diğer platformlarla ortaklıkların da kilidini açacak.

Nibi ve site sırasıyla Cloudflare Workers (Hono Server ile Interaction URL) ve React ile GitHub Pages tarafından barındırılıyor. Sitenin kodu açık kaynak değil ama Nibi açık kaynak ve onu bu GitHub deposunda bulabilirsin. Site özel bilgiler içerdiği için gizli kalıyor ama onu nasıl inşa ettiğimi bilmek istersen bana Discord üzerinden sor, süreci sana memnuniyetle anlatırım! GitHub Enterprise için ödeme yapmamak için oluşturduğum bir GitHub Action ve ilgini çekerse anlatabileceğim başka araçlar ve teknikler kullanıyor!

Birkaç gündür projelerimi barındırma için ödeme yapmadan barındırmak için geçici çözümler bulmaktan çok keyif alıyorum. Bu yüzden Nibi'yi Interaction Endpoint botu yaptım, Cloudflare Workers üzerinde ücretsiz barındırmak için, ve siteyi GitHub Pages üzerinde ücretsiz dağıtmak için bir GitHub Action oluşturdum. Bu geçici çözümleri aramak benim için kodun en heyecan verici kısımlarından biri olmaya devam ediyor: farklı düşünmek ve yaratıcı çözümler inşa etmek gerekiyor ve beni motive eden tam olarak bu bütçesiz meydan okuma!

GitHub Actions'ı tasarlanan kullanımının dışında kullanmak ve bir botu "barındırmak" için Cloudflare Workers kullanmak, aynı zamanda yeni şeyler öğrenmenin ve bulut barındırma gibi yeni teknolojiler keşfetmenin bir yolu. Artık barındırma için ödeme yapmak istemiyorum.

Hâlâ üzerinde çalışıyorum ama ilerlemeyi takip etmek ve nasıl geliştiğini görmek için Discord sunucusuna katılabilirsin, hatta ilgini çekerse projeye katılabilirsin bile! Sunucu herkese açık ve birlikte Japonca öğrenmek için daha fazla insan görmek isteriz! Davet bağlantısını sitede bulursun ya da doğrudan bana sorabilirsin!

Arbeit an einem neuen Projekt

March 13, 2026·4 min read

Fox3000foxyVerified@fox3000foxy

Ein Überblick über den Prozess, eine neue Website zu starten und zu entwickeln.

metawebdev
𝕏in

Das Projekt

Das Projekt, an dem ich arbeite, heißt LLJT:

Es ist eine Website, die auch eine PWA ist, also wie eine mobile App nutzbar. Sie nutzt MaterialUI, um sich wie eine echte Telefon-App zu verhalten. Ich habe eine Weile mit den Mui-Imports verbracht: Ich bin von 11707 Modulen am Ende auf 595 runtergekommen, indem ich jedes Icon Zeile für Zeile importiert habe statt des destrukturierten Imports. Ich habe damals gelernt, dass der destrukturierte Import die ganze Icon-Bibliothek lädt, während einzelne Imports nur die verwendeten laden.

Nibi ist der Bot, der mit dieser Website verbunden ist.Die Benotung basiert auf Google Forms: Wir nutzen Multiple-Choice-Tests, um unsere Schüler zu bewerten, und wir vergeben auch Discord-Rollen sowie Emojis und Channels an unsere Schüler, wenn sie eine wichtige Prüfung bestehen.

Das Ziel dieses Projekts ist es, Menschen zu helfen, gemeinsam mit uns Japanisch zu lernen, denn das ist etwas, das ich selbst auch machen will. Die Schüler schalten außerdem Partnerschaften mit Crunchyroll und anderen Plattformen frei, um ihren Fortschritt zu belohnen.

Nibi und die Seite werden jeweils von Cloudflare Workers (Interaction URL mit Hono Server) und GitHub Pages mit React gehostet. Der Code der Seite ist nicht Open Source, aber Nibi ist es, und du findest ihn in diesem GitHub-Repository. Die Seite bleibt privat, weil sie private Informationen enthält, aber wenn du wissen willst, wie ich sie gebaut habe, frag mich auf Discord und ich erkläre dir den Prozess gerne! Nibi इस वेबसाइट से जुड़ा बॉट है।मूल्यांकन Google Forms पर आधारित है : हम अपने छात्रों का मूल्यांकन करने के लिए MCQ का उपयोग करते हैं, और जब वे कोई महत्वपूर्ण परीक्षा पास करते हैं तो हम उन्हें Discord भूमिकाएँ, साथ ही इमोजी और चैनल भी देते हैं।

इस प्रोजेक्ट का लक्ष्य लोगों को हमारे साथ मिलकर जापानी सीखने में मदद करना है, क्योंकि यह कुछ ऐसा है जो मैं खुद भी करना चाहता हूँ। छात्र अपनी प्रगति के पुरस्कार के रूप में Crunchyroll और अन्य प्लेटफार्मों के साथ साझेदारी भी अनलॉक करेंगे।

Nibi और साइट क्रमशः Cloudflare Workers (Hono Server के साथ Interaction URL) और React के साथ GitHub Pages द्वारा होस्ट किए गए हैं। साइट का कोड ओपन सोर्स नहीं है, लेकिन Nibi है, और तुम इसे इस GitHub रिपॉजिटरी पर पा सकते हो। साइट निजी रहती है क्योंकि इसमें निजी जानकारी है, लेकिन अगर तुम जानना चाहते हो कि मैंने इसे कैसे बनाया, तो मुझसे Discord पर पूछो और मैं तुम्हें प्रक्रिया खुशी से समझाऊँगा ! यह एक GitHub Action का उपयोग करती है जिसे मैंने GitHub Enterprise के लिए भुगतान से बचने के लिए बनाया था, साथ ही कई अन्य उपकरण और तकनीकें जिनका मैं वर्णन कर सकता हूँ अगर तुम्हारी रुचि हो !

कुछ दिनों से, मुझे होस्टिंग के लिए भुगतान किए बिना अपने प्रोजेक्ट होस्ट करने के वैकल्पिक समाधान खोजने में बहुत मजा आ रहा है। इसीलिए मैंने Nibi को एक Interaction Endpoint बॉट बनाया, ताकि इसे Cloudflare Workers पर मुफ्त होस्ट किया जा सके, और साइट को GitHub Pages पर मुफ्त डिप्लॉय करने के लिए एक GitHub Action बनाई। ये वैकल्पिक रास्ते खोजना मेरे लिए कोड की सबसे प्रेरक बातों में से एक है : अलग तरह से सोचना पड़ता है और रचनात्मक समाधान बनाने पड़ते हैं, और यही बिना बजट की चुनौती मुझे प्रेरित करती है !

GitHub Actions का उसके नियत उपयोग के बाहर उपयोग करना, और एक बॉट को "होस्ट" करने के लिए Cloudflare Workers का उपयोग करना, नई चीजें सीखने और नई तकनीकों की खोज करने का एक तरीका भी है, जैसे क्लाउड होस्टिंग। मैं अब होस्टिंग के लिए भुगतान नहीं करना चाहता।

मैं अभी भी इस पर काम कर रहा हूँ लेकिन तुम Discord सर्वर से जुड़ सकते हो अगर तुम प्रगति का पालन करना चाहते हो और देखना चाहते हो कि यह कैसे विकसित होता है, और शायद प्रोजेक्ट से भी जुड़ सकते हो अगर तुम्हारी रुचि हो ! सर्वर सभी के लिए खुला है, और हम जापानी एक साथ सीखने के लिए और लोगों को पाकर खुश होंगे ! तुम्हें आमंत्रण लिंक साइट पर मिलेगा, या तुम मुझसे सीधे पूछ सकते हो !

Nibi والموقع مستضافان على التوالي بواسطة Cloudflare Workers (Interaction URL مع Hono Server) وGitHub Pages مع React. كود الموقع ليس مفتوح المصدر، لكن Nibi مفتوح، ويمكنك إيجاده على مستودع GitHub هذا. الموقع يبقى خاصا لأنه يحتوي على معلومات خاصة، لكن إذا أردت معرفة كيف بنيته، اسألني على Discord وسأشرح لك العملية بسرور ! يستخدم GitHub Action أنشأتها لتجنب دفع GitHub Enterprise، بالإضافة إلى عدة أدوات وتقنيات أخرى يمكنني أن أصفها لك إذا كان ذلك يهمك !

منذ أيام، أستمتع كثيرا بإيجاد حلول بديلة لاستضافة مشاريعي دون دفع استضافة. لهذا جعلت Nibi بوت Interaction Endpoint، لاستضافته مجانا على Cloudflare Workers، وأنشأت GitHub Action لنشر الموقع مجانا على GitHub Pages. البحث عن هذه الحلول البديلة يبقى بالنسبة لي من أكثر أجزاء البرمجة إثارة : يجب التفكير بشكل مختلف وبناء حلول إبداعية، وهذا التحدي بدون ميزانية هو بالضبط ما يحفزني !

استخدام GitHub Actions خارج استعماله المقصود، واستخدام Cloudflare Workers "لاستضافة" بوت، هو أيضا طريقة لتعلم أشياء جديدة واكتشاف تقنيات جديدة، مثل الاستضافة السحابية. لم أعد أريد الدفع مقابل الاستضافة.

ما زلت أعمل عليه لكن يمكنك الانضمام إلى سيرفر Discord إذا أردت متابعة التقدم ورؤية كيف يتطور، وربما حتى الانضمام إلى المشروع إذا كان ذلك يهمك ! السيرفر مفتوح للجميع، ونود أن يكون معنا المزيد من الناس لتعلم اليابانية معا ! ستجد رابط الدعوة على الموقع، أو يمكنك أن تطلبه مني مباشرة !

Dự án

Dự án tôi đang làm có tên là LLJT :

Đây là một trang web cũng là một PWA, nên có thể dùng như một ứng dụng di động. Nó dùng MaterialUI để hoạt động như một ứng dụng điện thoại thực thụ. Tôi đã tốn một lúc với các import Mui : tôi đã đi từ 11707 module xuống còn 595 cuối cùng, bằng cách import từng biểu tượng trên từng dòng thay vì dùng import destructuré. Tôi đã học được lúc đó rằng import destructuré tải toàn bộ thư viện biểu tượng, trong khi các import riêng lẻ chỉ tải những biểu tượng được dùng.

Nibi là bot kết nối với trang web này.Việc chấm điểm dựa trên Google Forms : Chúng tôi dùng trắc nghiệm để đánh giá học viên của mình, và chúng tôi cũng gán vai trò Discord, cùng emoji và kênh, cho các học viên khi họ vượt qua một kỳ thi quan trọng.

Mục tiêu của dự án này là giúp mọi người cùng học tiếng Nhật với chúng tôi, vì đó cũng là điều tôi muốn làm. Các học viên cũng sẽ mở khóa quan hệ đối tác với Crunchyroll và các nền tảng khác, để tưởng thưởng cho tiến trình của họ.

Nibi và trang web lần lượt được host bởi Cloudflare Workers (Interaction URL với Hono Server) và GitHub Pages với React. Mã nguồn của trang web không phải open source, nhưng Nibi thì có, và bạn có thể tìm thấy nó trên repo GitHub này. Trang web vẫn giữ riêng tư vì nó chứa thông tin riêng tư, nhưng nếu bạn muốn biết tôi đã xây dựng nó thế nào, hãy hỏi tôi trên Discord và tôi sẽ vui vẻ giải thích quy trình! Nó dùng một GitHub Action tôi đã tạo để tránh phải trả tiền GitHub Enterprise, cùng nhiều công cụ và kỹ thuật khác mà tôi có thể mô tả cho bạn nếu bạn quan tâm!

Mấy ngày qua, tôi rất thích tìm các giải pháp lách để host các dự án của mình mà không phải trả phí hosting. Đó là lý do tôi biến Nibi thành một bot Interaction Endpoint, để host nó miễn phí trên Cloudflare Workers, và đã tạo một GitHub Action để deploy trang web miễn phí trên GitHub Pages. Tìm kiếm những lối lách này vẫn là một trong những phần kích thích nhất của code đối với tôi : phải suy nghĩ khác đi và xây dựng các giải pháp sáng tạo, và chính thử thách không ngân sách này là điều thúc đẩy tôi!

Dùng GitHub Actions ngoài mục đích ban đầu của nó, và dùng Cloudflare Workers để "host" một bot, cũng là một cách học những điều mới và khám phá công nghệ mới, như cloud hosting. Tôi không muốn trả tiền hosting nữa.

Tôi vẫn đang làm dở nhưng bạn có thể tham gia máy chủ Discord nếu muốn theo dõi tiến độ và xem nó tiến triển thế nào, và có thể tham gia dự án nếu bạn quan tâm! Máy chủ mở cho mọi người, và chúng tôi muốn có thêm người cùng học tiếng Nhật với nhau! Bạn sẽ tìm thấy link mời trên trang web, hoặc bạn có thể hỏi trực tiếp tôi!

โครงการ

โครงการที่ฉันทำงานอยู่ชื่อ LLJT :

มันเป็นเว็บไซต์ที่ยังเป็น PWA ดังนั้นสามารถใช้เป็นแอปพลิเคชันมือถือได้ มันใช้ MaterialUI เพื่อให้พฤติกรรมเหมือนแอปโทรศัพท์จริง

ฉันใช้เวลาบางเวลาในเรื่องการ import ของ Mui: ฉันลดจาก 11707 โมดูลเหลือ 595 ในที่สุด โดย import ไอคอนทีละบรรทัด แทนการ import แบบ destructure. ฉันได้เรียนรู้ว่า import แบบ destructure จะโหลดทั้งห้องไลบรารีไอคอน ในขณะที่การ import แต่ละตัวจะโหลดเฉพาะที่ใช้เท่านั้น

Nibi คือบอทที่เชื่อมต่อกับเว็บไซต์นี้การให้คะแนนอาศัย Google Forms :

เราใช้แบบทดสอบทางเลือกมาก เพื่อประเมินนักเรียนของเรา และเรายังมอบบทบาท Discord รวมถึงอิโมจิและห้องแชทให้กับนักเรียนของเราเมื่อพวกเขาเกรดผ่านการสอบสำคัญ

เป้าหมายของโครงการนี้คือช่วยคนเรียนภาษาญี่ปุ่นร่วมกับเรา เพราะฉันเองก็อยากทำเช่นนั้นเช่นเดียวกัน

นักเรียนยังสามารถปลดล็อกความร่วมมือกับ Crunchyroll และแพลตฟอร์มอื่น ๆ เพื่อรางวัลความก้าวหน้าของพวกเขา

Nibi และเว็บไซต์ถูกโฮสต์โดย Cloudflare Workers (Interaction URL กับ Hono Server) และ GitHub Pages ด้วย React ตามลำดับ

โค้ดของเว็บไซต์ไม่ได้เป็นโอเพนซอร์ส แต่ Nibi เป็น และคุณสามารถค้นหาได้ใน ที่นี่บน GitHub เว็บไซต์ยังคงเป็นส่วนตัวเพราะมีข้อมูลส่วนตัว แต่ถ้าคุณอยากรู้ว่าฉันสร้างมันมาอย่างไร ถามฉันบน Discord แล้วฉันจะอธิบายกระบวนการให้คุณอย่างยินดี! มันใช้ GitHub Action ที่ฉันสร้างขึ้นเพื่อหลีกเลี่ยงการจ่ายเงิน GitHub Enterprise รวมถึงเครื่องมือและเทคนิคอื่น ๆ อีกหลายอย่างที่ฉันสามารถอธิบายให้คุณได้ถ้าคุณสนใจ

ในไม่กี่วันที่ผ่านมา ฉันสนุกกับการหาวิธีชิงบังคับเพื่อโฮสต์โปรเจกต์ของฉันโดยไม่ต้องจ่ายค่าโฮสต์ นั่นคือเหตุผลที่ฉันทำให้ Nibi เป็น bot Interaction Endpoint เพื่อโฮสต์ฟรีบน Cloudflare Workers และฉันสร้าง GitHub Action เพื่อปล่อยเว็บไซต์ฟรีบน GitHub Pages การค้นหาวิธีชิงบังคับเหล่านี้ยังคงเป็นหนึ่งในส่วนที่กระตุ้นฉันที่สุดของโค้ด: ต้องคิดอย่างต่าง และสร้างวิธีแก้แบบสร้างสรรค์ และนี่คือความท้าทายโดยไม่มีงบประมาณที่ทำให้ฉันมีแรงจูงใจ

การใช้ GitHub Actions นอกเหนือจากการใช้งานที่ตั้งใจไว้ และการใช้ Cloudflare Workers เพื่อ "โฮสต์" บ็อต นั้นก็เป็นวิธีหนึ่งในการเรียนรู้สิ่งใหม่ ๆ และค้นพบเทคโนโลยีใหม่ ๆ เช่นการให้บริการบนคลาวด์ ฉันไม่ต้องการจ่ายเงินเพื่อการโฮสต์อีกต่อไป

ฉันทำงานกับมันต่อไปอีก แต่คุณสามารถเข้าร่วม เซิร์ฟเวอร์ Discord หากคุณอยากติดตามความคืบหน้าและดูว่าเป็นอย่างไร และอาจเข้าร่วมโครงการหากสนใจ! เซิร์ฟเวอร์เปิดให้ทุกคน และเราต้องการให้มีคนมากขึ้นเพื่อเรียนภาษาญี่ปุ่นร่วมกัน! คุณจะพบลิงก์เชิญบนเว็บไซต์ หรือคุณสามารถขอฉันได้โดยตรง!
