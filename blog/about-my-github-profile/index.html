내 GitHub 프로필

헤더와 링크

잘 정리된 도서관처럼 꾸며 놓은 제 GitHub 프로필에 오신 것을 환영해요. 첫 번째 섹션에는 링크가 있는 헤더가 있는데, 방문하자마자 방향을 잡아 주기에 효과적인 꽤 표준적인 형식이라고 생각해요.

여기에서 제 프로젝트와 연락처, 그리고 이 사이트로 이어지는 주요 링크들을 찾으실 수 있어요. 저장소를 뒤지지 않고 핵심 내용에 바로 접근하실 수 있도록 위에 모아 두었어요.

저에 대하여

"저에 대하여" 섹션도 있어요.

이 섹션에서는 제가 지금 무엇을 하고 있는지 실시간으로 보실 수 있어요. 제가 음악을 듣고 있는 게 보인다면, 아마 플레이리스트를 틀어 놓고 코딩하고 있을 거예요. 여기에도 표시기를 달아 둘게요.

실시간 상태

기술 스택

다음은 제 기술 스택이에요. 매일 실제로 능숙하게 다루는 언어와 도구들을 모아 놓았어요.

GitHub 통계

아래는 제 GitHub 통계예요. 여러 개의 작은 그래프로 나누어져 있어요.

활동과 지표

기여 히트맵

그리고 제 커밋들이 히트맵에 팩맨 모양을 그리고 있어요. 한 해의 기여를 돌아볼 때마다 이 작은 시각적 장난이 정말 마음에 들어요.

프로젝트

아래에는 모든 저장소를 카테고리별로 정리해 두었어요. 관심 있는 분야가 있다면 한번 들러 보세요. 거의 모든 저장소에 대해 블로그 글을 하나씩 쓸 예정이에요.

정리하자면

제 GitHub 프로필 이야기는 여기까지예요. 방문이 즐거우셨길 바라요. 각 프로젝트마다 글을 쓸 예정이니 가끔 다시 들러 주세요. 질문이 있거나 함께 작업하고 싶은 것이 있다면 Discord나 GitHub으로 연락해 주세요. 방문해 주셔서 감사해요!

मेरा GitHub प्रोफ़ाइल

हेडर और लिंक

मेरे GitHub प्रोफ़ाइल में आपका स्वागत है, इसे एक करीने से सजी लाइब्रेरी की तरह व्यवस्थित किया गया है। पहले खंड में लिंक वाला एक हेडर है, यह काफी मानक प्रारूप है जो मुझे आगमन पर ही दिशा देने के लिए प्रभावी लगता है :

यहाँ तुम्हें मेरे मुख्य लिंक मिलेंगे, जो मेरे प्रोजेक्टों, मेरे संपर्क और इस साइट की ओर ले जाते हैं। मैंने इन्हें सबसे ऊपर रखा है ताकि तुम रिपॉजिटरी में खोजबीन किए बिना सीधे जरूरी चीजों तक पहुँच सको।

मेरे बारे में

यहाँ "मेरे बारे में" खंड भी है :

इस खंड में तुम देखते हो कि मैं इस समय क्या कर रहा हूँ। अगर तुम मुझे संगीत सुनते देखो, तो शायद मैं पृष्ठभूमि में अपनी प्लेलिस्ट के साथ कोडिंग कर रहा हूँ। मैं सूचक भी यहीं रखता हूँ :

लाइव स्थिति

GitHub आँकड़े

नीचे मेरे GitHub आँकड़े हैं, जो कई छोटे ग्राफों में बँटे हैं :

गतिविधि और मेट्रिक्स

योगदान का हीटमैप

और यहाँ मेरे कमिट हैं जो योगदान हीटमैप में एक PacMan बनाते हैं। जब मैं अपने साल भर के योगदानों को दोबारा देखता हूँ तो मुझे यह छोटा दृश्य संकेत बहुत पसंद आता है।

प्रोजेक्ट

नीचे मेरे सभी रिपॉजिटरी श्रेणी के अनुसार व्यवस्थित हैं। अगर कोई क्षेत्र तुम्हारी रुचि का हो तो एक नजर डालो। मैं उनमें से लगभग हर एक के लिए एक ब्लॉग लेख लिखने की योजना बना रहा हूँ :

संक्षेप में

मेरे GitHub प्रोफ़ाइल के बारे में इतना ही, उम्मीद है तुम्हें यह यात्रा पसंद आई। मैं अपने हर प्रोजेक्ट के लिए एक लेख लिखूँगा, इसलिए समय समय पर वापस आते रहो। अगर तुम्हारे कोई प्रश्न हों या तुम किसी चीज पर सहयोग करना चाहो, तो Discord पर या GitHub के माध्यम से मुझसे संपर्क करो। तुम्हारी यात्रा के लिए धन्यवाद !
