# Проект

Проект, над которым я работаю, называется LLJT :

![](assets/20260313_092734_image.png)

Это сайт, который ещё и PWA, так что им можно пользоваться как мобильным приложением. Он использует MaterialUI, чтобы вести себя как настоящее приложение на телефоне.
Я провозился с импортами Mui : перешёл с 11707 модулей до 595 в конце, импортируя каждую иконку отдельной строкой вместо деструктурирующего импорта. Тогда я узнал, что деструктурирующий импорт тянет всю библиотеку иконок, а отдельные импорты грузят только используемые.

Nibi это бот, подключённый к этому сайту.![](assets/20260313_093102_image.png)Оценивание построено на Google Forms :
![](assets/20260313_093255_image.png)
Мы используем тесты с вариантами ответов, чтобы оценивать наших студентов, а ещё выдаём роли в Discord, а также эмодзи и каналы, нашим студентам, когда они сдают важный экзамен.

![](assets/20260313_093707_image.png)

Цель этого проекта помочь людям учить японский вместе с нами, потому что я и сам хочу этим заниматься.
Студенты также будут открывать партнёрства с Crunchyroll и другими платформами в награду за прогресс.

Nibi и сайт хостятся соответственно на Cloudflare Workers (Interaction URL с Hono Server) и GitHub Pages с React.
Код сайта не открытый, а вот Nibi открыт, и ты найдёшь его в [этом репозитории GitHub](https://github.com/let-s-Learn-Japanese-Together/nibi). Сайт остаётся приватным, потому что там приватная информация, но если хочешь узнать, как я его строил, спроси меня в Discord, и я с радостью объясню процесс! Он использует GitHub Action, который я создал, чтобы не платить за GitHub Enterprise, а также несколько других инструментов и приёмов, про которые я могу рассказать, если тебе интересно!

Последние дни мне очень нравится искать обходные пути, чтобы хостить проекты, не платя за хостинг. Поэтому я сделал Nibi ботом на Interaction Endpoint, чтобы бесплатно хостить его на Cloudflare Workers, и создал GitHub Action, чтобы бесплатно деплоить сайт на GitHub Pages. Поиск таких обходных путей остаётся для меня одной из самых заряжающих частей кода : нужно думать иначе и строить креативные решения, и именно этот вызов без бюджета меня и мотивирует!

Использовать GitHub Actions не по назначению и использовать Cloudflare Workers, чтобы "хостить" бота, это ещё и способ учить новое и открывать новые технологии вроде облачного хостинга. Я больше не хочу платить за хостинг.

Я всё ещё над ним работаю, но ты можешь зайти на [сервер Discord](https://discord.gg/frKZ9cJ4fD), если хочешь следить за прогрессом и видеть, как всё развивается, а может, даже присоединиться к проекту, если тебе интересно! Сервер открыт для всех, и нам хотелось бы видеть больше людей, чтобы учить японский вместе! Ссылку-приглашение ты найдёшь на сайте, или можешь попросить её у меня напрямую!
