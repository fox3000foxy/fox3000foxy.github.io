## 引言

![拿火箭筒瞄准的 TF2 士兵机器人](assets/tf2-bot-ai-soldier-aim.png)

每个 TF2 玩家都说过至少一次："这机器人开挂。"或者反过来："简单机器人为什么杵着吃火箭。"没人真知道"简单"、"普通"、"困难"、"专家"在底下是什么意思：Valve 发了四个难度标签，零文档。

于是我们一帮人（我、awimii、Mush The Possum，最大头的基础工作是真翻了反编译代码的 sigsegv）攒了份 TFBot 行为完整研究文档。每个机制、每个已知 bug、每个写死的概率。这篇是完整版，不是精简版。开瓶 Bonk，坐长了。

## 第一章：基础

### 机器人 vs 木偶机器人

TF2 里大家嘴里的"机器人"是完全两种东西：

- **AI 机器人（TFBot）**：真 AI，和 Valve 给 *Left 4 Dead* 用的 PlayerBot/Infected 同框架。随机选职业，打目标，不用 `sv_cheats`，像真玩家一样触发成就。
- **木偶机器人**：零 AI，自己不会动不会打。只给人手动遥控用，玩家让它跟随、瞄准、开火。主要给测试、截图、拍片。刷出来要 `sv_cheats 1`，这 session 成就也关了。

这篇只讲第一种。

### AI 机器人能（差不多）指挥动什么

TFBot 不能直接控制，但能哄着干点事：

- 准星指着任何机器人（友军敌军都行），用对的语音命令它会嘲讽你。
- 友军医生机器人，你喊"Medic!"它给你奶。
- 奶你的医生有满 Uber，你喊"Go go go!"或"开冲！"它立刻开。不用语音也行。
- 有满 Uber 的医生，自己或奶的人掉血狠了，不用喊自动开。
- 机器人和近距离队友自发双人嘲讽（High Five）或组嘲（Conga）。

### 让机器人在没导航的图上跑

机器人走路靠导航网格，没导航的社区图它们寸步难行。强制办法：

1. `sv_cheats 1`
2. `nav_generate`，建初始导航网格，进度打控制台
3. 等游戏算完路
4. 可选用 `nav_edit 1` 手修烂导航数据
5. 重载或重启服务器（不做这步成就关着）
6. `tf_bot_add <数量>` 刷机器人

**警告：** 服务器上有活跃机器人时改导航可能直接崩盘。网格建好以后不用重建：以后直接 `tf_bot_add` 加人。

自生成网格在占点、山丘之王、推车、夺旗图上最好用。Mannpower 图机器人默认按夺旗打，钩子和加成基本不用。图上没机器人认识的目标、但有出生室实体，把 `tf_bot_offense_must_push_time` 置 0，机器人照样打。

*（这节来源：TF2 官方 wiki 机器人页。）*

### 各图现状，一个个来

Hatless 更新后各职业全修好了，包括历史上 bug 堆成山的间谍。机器人大多数官方 KOTH 图正常，部分推车图正常，Dustbowl/Gorge 攻防和夺旗/Mann Manor 正常。后两种不能直接 `tf_bot_add` 刷。没支持的图（上面 `nav_generate` 流程走一遍）能跑，但装真人差很多。

PLR 图没救：Hightower 机器人过不了栅栏卡角落，别的所有 PLR 图它们只……开蹦迪派对不打。以后修不修随缘吧。

### 机器人通用行为

所有难度共有的大杂烩：

- 机器人只用默认配置（插件能硬塞非标武器，vanilla 机器人自己不换）。
- 简单机器人基本不用副武器。高难度主弹夹打空切副，或按距离切。
- 机器人不用高级身法：不火箭跳，不搬建筑。
- 杀完人机器人可能嘲讽，枪林弹雨也嘲，除非抱着敌方情报，MvM 也一样。
- 伪装间谍（玩家或 AI）别的机器人正确无视：直到它摸人、炸东西、开枪、近处隐身。一旦"识破"，这个具体机器人/玩家记成间谍，直到它隐身换装、死了、或 Dead Ringer 装死。
- 火焰兵普通起用压缩气爆随便吹。
- 医生奶人优先级：除了狙击手（工程师也往后稍）谁都奶，哪怕你玩狙击手刷"Medic!"。
- 医生往人类玩的重装、士兵、爆破、火焰兵身边凑：专盯**人类**玩这些职业。这个跟随看人类面子。
- 攻防和推车准备时间机器人原地站：工程师、狙击、间谍随便走（爆破兵也允许预埋粘弹）。
- 工程师机器人不升级不拆友军工程师的建筑，除非挡它目标路。有时连自己炮都不修，看着急死。
- 识破的间谍机器人切左轮往后退，不硬拼刀。
- 哪里死的在哪记住的爆破兵，能隔着掩体抛物线把粘弹完美扔进哨兵射程外，穿墙穿天花板看几何。
- 找不到目标瞄半天的狙击机器人来句"Negatives."语音。
- 友军医生奶伪装间谍不带犹豫。

### 已知问题 / bug

文档列了堆陈年怪事：

- 机器人能试着穿某些静态道具走路开枪。
- 玩家/机器人每次掏枪、伪装、现形，附近机器人"看"见了回头反应：哪怕事件发生在真实视野外。不靠声音，是视野检测的绕过。
- 极少数机器人挤着过工程师传送门能互相卡死。
- 机器人语音命令（如"Spy!"、"冲！"）不像玩家一样打字幕。
- 奶人的医生机器人不躲子弹，残血不捡医疗包。
- 双人嘲讽进行中机器人能继续移动，Festive Critical Strike 预期效果没了。
- 刚挨打的医生经常远程掏针枪不用，非贴脸（极少数还拿医疗枪光束捅你）。
- 医生不给针枪弹道补偿重力：大概率代码 AI 里这武器没标非 hitscan。
- 间谍机器人能看见跟住隐身间谍（玩家或 AI），只要这间谍被识破过一次，跟的人什么难度都行。
- 玩家间谍哪怕伪装成本队职业，撞敌人一下就现形（机器人自己从不伪装成本队，所以它们没这事）。
- 机器人守队伍自动平衡：想一边堆人，先 `mp_teams_unbalance_limit 0`。
- 工程师机器人能彻底无视自己建筑直到被拆。
- 困难以下重装有时刻着 Minigun 空枪扣，明明没子弹。
- 输的一方医生在羞辱阶段附近没敌人时偶尔自杀，人类玩家想学都学不来。
- 加载界面队伍预览选 BLU，RED 机器人你看着像蓝的。
- 掏近战的机器人捡了子弹有时不切枪。
- Jungle Inferno 之后带显式参数刷的机器人（如 `tf_bot_add 5 pyro bleu normal`）可能出生在自己复活点暴毙。修：`tf_bot_reevaluate_class_in_spawnroom 0`（要 `sv_cheats 1`）。

### AI 名字

机器人名字从大池子抽，TF2 梗、别的 Valve 游戏梗、编程梗，因为社区在 Steam 论坛点名要得太多。抽几个：*AimBot、Aperture Science Prototype XR7、Black Mesa、Companion Cube、C++、Divide by Zero、GLaDOS、H@XX0RZ、Saxton Hale、The G-Man、trigger_hurt、0xDEADBEEF*，几十个同味。

还有批泄露源码 build 里有、正式版没发的，原因不明：主要是 *Last Dragon* 和 *Fifth Element* 梗，如 *John Spartan、Leeloo Dallas Multipass、Sho'nuff、Bruce Leroy、Big Gulp Huh?* 和 *I'm your huckleberry*。

全能自己换：`tf_bot_add heavyweapons blue "Blu Hoovy"` 刷个叫"Blu Hoovy"的蓝重装。

## 第二章：原生机器人 / TFBot，难度深潜

Sigsegv 的原框架依然成立：专家显然强过简单，但 Valve 从没说过*强多少*、*为什么*。只能读代码。每个随难度变的机制都在下面。

### 调难度

MvM 外难度走 cvar：

| `tf_bot_difficulty` | 难度 |
| --- | --- |
| 0 | 简单 |
| 1 | 普通（默认） |
| 2 | 困难 |
| 3 | 专家 |

`tf_bot_add` 也能直接带难度参数（`easy`/`normal`/`hard`/`expert`）。

### MvM popfile

Mann vs. Machine 里每个 TFBot 生成块的 `Skill` key 可选。不写等于简单。Valve 官方任务：巨人几乎全专家，工程师和间谍几乎全专家，狙击一般困难（偶尔专家）。`EventChangeAttributes`（Two Cities 更新加的）能在波次中按地图事件动态改机器人，难度是能热改的属性之一。

### 无尽 MvM 模式

无尽模式从没正式发，里面机器人像玩家一样花钱升级，包括一条机器人专属升级：对局中涨 AI 难度。

### `bot_generator` 实体

巨冷门、基本没文档的实体，疑似训练模式用过，MvM 早期开发也许用过。暴露 `SetDifficulty` 输入调难度。再往下没了：Valve 没写过文档，没人完整摸过它的行为。

### 眼睛辉光颜色

MvM 机器人眼睛粒子颜色随难度变，社区外没人解释过的视觉指示：

| 难度 | 眼睛颜色 | RGB |
| --- | --- | --- |
| 简单/普通 | 蓝 | `#24b4ff` |
| 困难/专家 | 黄 | `#fff000` |

![待机重装机器人](assets/tf2-bot-ai-heavy-idle.png)

### 视野：认出时间

东西进视野机器人不立刻反应：硬编码延迟，剩下的 AI 在此之前连威胁都不认：

| 难度 | 最小认出时间 |
| --- | --- |
| 简单 | 1.00 秒 |
| 普通 | 0.50 秒 |
| 困难 | 0.30 秒 |
| 专家 | 0.20 秒 |

"简单机器人看着傻"大半就这一个数字：简单机器人认出你之后瞄得不差，只是认出你要慢五倍。

### 瞄准：追踪频率

机器人不连续跟你。固定间隔采样你的位置速度，直线外推：

| 难度 | 重算间隔 | 等效频率 |
| --- | --- | --- |
| 简单 | 1.00 秒 | 1 次/秒 |
| 普通 | 0.25 秒 | 4 次/秒 |
| 困难 | 0.10 秒 | 10 次/秒 |
| 专家 | 0.05 秒 | 20 次/秒 |

**例外：** 间谍机器人写死普通追踪频率，不管真实难度：专家间谍瞄准也像普通。还有公开对比演示视频，并排看 1x 对 20x 的差距。

### 瞄准：分武器逻辑

机器人不瞄你质心，有分武器逻辑，有的真 bug：

**榴弹枪和粘弹枪。** 全难度补偿纵向弧线，用 `tf_bot_notice_gunfire_range` cvar 定值。但补偿只认基础武器 ID 更快的弹道变体（Loch-n-Load、一切弹速 mod）弧线算不准。按武器 ID 绑的，Loose Cannon（ID 不同）完全没弧线补偿。

**猎人。** 简单不补偿箭下坠，不找爆头。普通补偿弧线，但 150 HU 内才瞄头。困难/专家永远瞄头。

**火箭筒。** 150 HU 外非简单瞄脚不瞄质心，最大化范围伤害和击飞。150 HU 内转爆头。简单永远质心不管距离。也是武器 ID 锁：Direct Hit 和 Cow Mangler 没这行为。Direct Hit 合理（没范围可炸），Cow Mangler 没道理：这段 AI 比这武器老，从没回头看过。

**狙击枪。** 简单瞄身。普通瞄身往头约 1/3 处。困难/专家直接头。MvM 里轻点，机器人爆头没伤害加成。

### 听觉：安静开火敏感度

每声枪响 3000 HU 内附近机器人全听见位置（`tf_bot_notice_gunfire_range`），穿墙，100% 注意。但一小撮武器标"安静"：只 500 HU 内听见（`tf_bot_notice_quiet_gunfire_range`），听见还看难度掷骰：

| 难度 | 听见安静开火概率 |
| --- | --- |
| 简单 | 10% |
| 普通 | 30% |
| 困难 | 60% |
| 专家 | 90% |

3 秒内听过*响*枪，概率减半：响声盖住轻声。

安静武器 ID 表 2010 年 12 月后没更新过。用新 ID 的后来武器默认全算响，不管逻辑上多安静，除非复用老 ID。具体：

| 武器 ID | 覆盖 |
| --- | --- |
| `TF_WEAPON_KNIFE` | 全部间谍刀 |
| `TF_WEAPON_FISTS` | 重装专属拳头（它多职业拳头其实是 `TF_WEAPON_FIREAXE`） |
| `TF_WEAPON_PDA` | 疑似没直接用过 |
| `TF_WEAPON_PDA_ENGINEER_BUILD` | 工程师建造 PDA |
| `TF_WEAPON_PDA_ENGINEER_DESTROY` | 工程师拆除 PDA |
| `TF_WEAPON_PDA_SPY` | 间谍伪装盒 |
| `TF_WEAPON_BUILDER` | 间谍/工程师/工兵工具 |
| `TF_WEAPON_MEDIGUN` | 全部医疗枪 |
| `TF_WEAPON_DISPENSER` | 大概没用过（补给器是物件不是武器） |
| `TF_WEAPON_INVIS` | 全部间谍隐身表 |
| `TF_WEAPON_FLAREGUN` | 全部火焰兵信号枪*除 Manmelter* |
| `TF_WEAPON_LUNCHBOX` | 三明治、Dalokohs、牛排、Bonk!、Crit-a-Cola |
| `TF_WEAPON_JAR` | Jarate（Mad Milk 是独立 ID，算响） |
| `TF_WEAPON_COMPOUND_BOW` | 猎人 |
| `TF_WEAPON_SWORD` | Eyelander、Skullcutter、Claidheamh Mor、Persian Persuader、Half-Zatoichi |
| `TF_WEAPON_CROSSBOW` | 十字军弩 |

表烂掉的经典：Manmelter 拿了独立 ID（`TF_WEAPON_RAYGUN_REVENGE`），安静表冻结之后加的，所以算响，明明实际就是信号枪。更晚的 Scorch Shot 复用基础 `TF_WEAPON_FLAREGUN` ID，所以一直算安静。离谱，但是代码。

### 策略：威胁优先级

多敌人同时可见，机器人按距离、谁在打我、普通以上看主要威胁有没有被奶，掂量：

| 难度 | 转打奶妈吗？ |
| --- | --- |
| 简单 | 不 |
| 普通 | 50% 概率 |
| 困难 | 打 |
| 专家 | 打 |

500 HU 外敌人一般降级非迫切。例外：困难/专家永远把远处医生和工程师当迫切，任何瞄着你大方向的敌方狙击永远迫切，不管距离难度。

| 难度 | 远处医生/工程师/瞄你的狙击 = 迫切吗？ |
| --- | --- |
| 简单/普通 | 不 |
| 困难/专家 | 是 |

狙击这条有个我超爱讲的考据。Sigsegv 原文以为游戏要求狙击瞄准向量和机器人相对位置点积*精确等于零*：浮点比较严到几乎永不触发，整功能等于死代码。后来更干净的 Hex-Rays 反编译修正（credit 归它）真实检查是*点积 > 0*：正对你到侧对你的狙击全算迫切，侧对到背对不算。原误读来自浮点 SSE 比较的坏反编译。给 17 年 AAA 二进制做逆向，永远是近似活。

### 移动：闪避

简单机器人永不闪避，就这样。普通以上满足就左右闪（左 33%、右 33%、不动 33%，探到坑加权）：拿着战斗武器、3 秒内见过敌人、敌人能直视它。

这些情况*不*闪：有 `DisableDodge` 属性、当前行为叫快跑、任何无敌（uber）、嘲讽/挑衅中、玩工程师、间谍隐身或伪装、狙击开镜或重装转枪管、拉猎人弓。

### 移动：别撞敌人

普通以上移动特意不撞敌人：

| 难度 | 避撞敌人吗？ |
| --- | --- |
| 简单 | 不 |
| 普通 | 不 |
| 困难 | 避 |
| 专家 | 避 |

实际只对间谍机器人重要：别扭地撞玩家正是暴露伪装的招牌。

### 火焰兵：气爆掌握

气爆两用：反弹道（PvP 和 MvM）、推悬崖边敌人（只 PvP）。机会来了按不按，看难度掷骰：

| 难度 | 气爆概率 |
| --- | --- |
| 简单 | 0% |
| 普通 | 50% |
| 困难 | 90% |
| 专家 | 100% |

简单火焰兵字面不会气爆：掷骰写死永不中，不是"很少"。

### 间谍：伪装效率

两条轴随难度变。伪装*选角*：

| 难度 | 伪装方法 |
| --- | --- |
| 简单/普通 | 随机职业，不管敌方阵容 |
| 困难/专家 | 抄真敌方玩家，职业照搬 |

伪装*行为*：

| 难度 | 伪装/隐身行为 |
| --- | --- |
| 简单/普通 | 看见敌方玩家就盯（可疑） |
| 困难/专家 | 故意避视线接触（像真的） |

### 间谍：背刺侵略性

远距离（300 HU 内，`tf_bot_spy_knife_range`）间谍机器人只在看得见受害者、且背至少部分转过来时拼背刺。难度定背能偏多少：

| 难度 | 角度容忍 |
| --- | --- |
| 简单 | 你正脸看它也拼 |
| 普通 | 背左右 ±45° |
| 困难 | 背左右 ±78° |
| 专家 | 背左右 ±90°（整 180° 后半弧） |

简单间谍功能性自杀：盯着你脸也捅。**例外：** Mann vs. Machine 全间谍机器人强制普通角，不管真实难度。

### 战术：切枪

逻辑只管困难以上，MvM 兴趣不大（机器人武器一般锁死）：

- **侦察兵**：主弹夹空切副。
- **士兵**：弹夹空*且*目标 500 HU 内切副。
- **狙击**：750 HU 内目标切副。
- **火焰兵**：750 HU 外目标切副，目标是士兵或爆破不切。

## 结语

![拿 minigun 瞄准的重装机器人](assets/tf2-bot-ai-heavy-aim.png)

这些反映 Valve 一套故意的系统：全确定性分数概率，只是官方从没写过文档。深潜完我记住三点：

1. **"难度"是一堆独立旋钮**，不是全局倍率。反应时间、瞄准频率、每条战术行为各走各的，有的（间谍追踪频率、MvM 背刺角）写死覆盖不管难度。
2. **一部分真是 bug，不是老。** 2010 年冻结的安静武器表、没道理没打脚逻辑的 Cow Mangler、狙击点积检查花几年才反编译对：17 年代码库全是 Valve 的疤。
3. **全能用上。** 知道普通狙击机器人不爆你头，简单火焰兵字面反射不了你火箭，简单间谍敢你脸上捅刀。这不是运气。是技术表。

巨感谢 sigsegv 原创代码深潜，没有它大半不可能，感谢 TF2 wiki 机器人命令和地图支持基础文档，感谢社区里折腾 17 年老 bot AI、非要搞清它为什么这么干的所有人。
