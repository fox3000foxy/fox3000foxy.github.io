# प्रोजेक्ट

जिस प्रोजेक्ट पर मैं काम कर रहा हूँ उसका नाम LLJT है :

![](assets/20260313_092734_image.png)

यह एक वेबसाइट है जो एक PWA भी है, इसलिए मोबाइल एप्लिकेशन की तरह इस्तेमाल की जा सकती है। यह असली फोन एप्लिकेशन जैसा व्यवहार करने के लिए MaterialUI का उपयोग करती है।
मैंने Mui इम्पोर्ट पर कुछ समय बिताया : मैं अंत में 11707 मॉड्यूल से 595 पर आ गया, हर आइकन को डिस्ट्रक्चर्ड इम्पोर्ट के बजाय पंक्ति दर पंक्ति इम्पोर्ट करके। तब मैंने सीखा कि डिस्ट्रक्चर्ड इम्पोर्ट आइकन की पूरी लाइब्रेरी लोड करता है, जबकि व्यक्तिगत इम्पोर्ट सिर्फ इस्तेमाल किए गए आइकन लोड करते हैं।

Nibi इस वेबसाइट से जुड़ा बॉट है।![](assets/20260313_093102_image.png)मूल्यांकन Google Forms पर आधारित है :
![](assets/20260313_093255_image.png)
हम अपने छात्रों का मूल्यांकन करने के लिए MCQ का उपयोग करते हैं, और जब वे कोई महत्वपूर्ण परीक्षा पास करते हैं तो हम उन्हें Discord भूमिकाएँ, साथ ही इमोजी और चैनल भी देते हैं।

![](assets/20260313_093707_image.png)

इस प्रोजेक्ट का लक्ष्य लोगों को हमारे साथ मिलकर जापानी सीखने में मदद करना है, क्योंकि यह कुछ ऐसा है जो मैं खुद भी करना चाहता हूँ।
छात्र अपनी प्रगति के पुरस्कार के रूप में Crunchyroll और अन्य प्लेटफार्मों के साथ साझेदारी भी अनलॉक करेंगे।

Nibi और साइट क्रमशः Cloudflare Workers (Hono Server के साथ Interaction URL) और React के साथ GitHub Pages द्वारा होस्ट किए गए हैं।
साइट का कोड ओपन सोर्स नहीं है, लेकिन Nibi है, और तुम इसे [इस GitHub रिपॉजिटरी](https://github.com/let-s-Learn-Japanese-Together/nibi) पर पा सकते हो। साइट निजी रहती है क्योंकि इसमें निजी जानकारी है, लेकिन अगर तुम जानना चाहते हो कि मैंने इसे कैसे बनाया, तो मुझसे Discord पर पूछो और मैं तुम्हें प्रक्रिया खुशी से समझाऊँगा ! यह एक GitHub Action का उपयोग करती है जिसे मैंने GitHub Enterprise के लिए भुगतान से बचने के लिए बनाया था, साथ ही कई अन्य उपकरण और तकनीकें जिनका मैं वर्णन कर सकता हूँ अगर तुम्हारी रुचि हो !

कुछ दिनों से, मुझे होस्टिंग के लिए भुगतान किए बिना अपने प्रोजेक्ट होस्ट करने के वैकल्पिक समाधान खोजने में बहुत मजा आ रहा है। इसीलिए मैंने Nibi को एक Interaction Endpoint बॉट बनाया, ताकि इसे Cloudflare Workers पर मुफ्त होस्ट किया जा सके, और साइट को GitHub Pages पर मुफ्त डिप्लॉय करने के लिए एक GitHub Action बनाई। ये वैकल्पिक रास्ते खोजना मेरे लिए कोड की सबसे प्रेरक बातों में से एक है : अलग तरह से सोचना पड़ता है और रचनात्मक समाधान बनाने पड़ते हैं, और यही बिना बजट की चुनौती मुझे प्रेरित करती है !

GitHub Actions का उसके नियत उपयोग के बाहर उपयोग करना, और एक बॉट को "होस्ट" करने के लिए Cloudflare Workers का उपयोग करना, नई चीजें सीखने और नई तकनीकों की खोज करने का एक तरीका भी है, जैसे क्लाउड होस्टिंग। मैं अब होस्टिंग के लिए भुगतान नहीं करना चाहता।

मैं अभी भी इस पर काम कर रहा हूँ लेकिन तुम [Discord सर्वर](https://discord.gg/frKZ9cJ4fD) से जुड़ सकते हो अगर तुम प्रगति का पालन करना चाहते हो और देखना चाहते हो कि यह कैसे विकसित होता है, और शायद प्रोजेक्ट से भी जुड़ सकते हो अगर तुम्हारी रुचि हो ! सर्वर सभी के लिए खुला है, और हम जापानी एक साथ सीखने के लिए और लोगों को पाकर खुश होंगे ! तुम्हें आमंत्रण लिंक साइट पर मिलेगा, या तुम मुझसे सीधे पूछ सकते हो !
